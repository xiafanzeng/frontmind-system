# 内容策略方法论

> E1 内容策略师在执行选题规划时必须遵循本方法论。本文档定义了从策略包解读到选题矩阵输出的完整方法体系。

---

## 一、策略翻译框架

### 1.1 策略包解读三步法

**第一步：提取品牌核心要素**

从 S1（品牌事实图谱）和 S4（品牌定位）中提取：

| 要素类别 | 提取内容 | 用于 |
|:---|:---|:---|
| 品牌身份 | 企业名称、成立时间、规模、资质 | 文章中的事实素材 |
| 差异化主张 | 核心竞争优势（≥3 条） | 选题方向和标题设计 |
| 目标受众 | 决策者画像、痛点列表 | 内容角度和语气选择 |
| 竞争格局 | 主要竞品及其定位 | A1/A2/A6 类聚合文章的品牌选择 |

**第二步：映射问题路径触点**

从 S8（问题路径地图）中提取客户问题路径各阶段的关键触点，映射到内容类型：

| 问题阶段 | 典型触点 | 适配内容类型 | 优先级 |
|:---|:---|:---|:---|
| 认知（Awareness） | AI 搜索、社媒浏览 | A1/A9/C1b/C2 | 首批必做 |
| 考虑（Consideration） | 深度搜索、对比研究 | A3/A6/A8/B3 | 首批推荐 |
| 决策（Decision） | 案例查阅、白皮书下载 | B1/B3/A8 | 第二批 |
| 使用（Usage） | 技术文档、教程 | A11/B2/B4 | 持续 |
| 倡导（Advocacy） | 社媒分享、口碑传播 | C3/C4 | 持续 |

**第三步：对齐渠道建议**

从 S9（赋能建议）中提取渠道推荐，确保每篇内容有明确的分发目标：

| 渠道类型 | 典型平台 | 适配内容类型 | 发布频率 |
|:---|:---|:---|:---|
| 自有媒体 | 百家号/搜狐号/知乎 | A 类全部 | 每周 1-2 篇 |
| 新闻媒体 | 新浪/网易/腾讯新闻 | C1a/C1b/C2 | 每月 1-2 篇 |
| 专业平台 | 行业垂直媒体 | B 类/A9/A12 | 每季度 1-2 篇 |
| 社交媒体 | 微信/微博/抖音 | D 类（E5 适配） | 每周 2-3 条 |
| 官网/博客 | 企业官网 | A/B 类精选 | 每月 2-3 篇 |

### 1.2 选题优先级评估模型

每篇候选文章使用以下五维评估模型确定优先级：

| 维度 | 权重 | 评估标准 |
|:---|:---|:---|
| AI 搜索匹配度 | 30% | 目标搜索词的 AI 平台覆盖率 |
| 问题阶段重要性 | 25% | 该阶段的转化影响力 |
| 竞争空白度 | 20% | 竞品在该话题的内容密度 |
| 品牌素材丰富度 | 15% | S1 中可用的事实素材量 |
| 渠道适配性 | 10% | 目标渠道的内容偏好匹配度 |

**优先级分档**：
- **P0（首发）**：综合评分 ≥ 80 分，必须在首批生产
- **P1（推荐）**：综合评分 60-79 分，建议在首批或第二批生产
- **P2（备选）**：综合评分 < 60 分，根据资源情况安排

---

### 1.3 品牌传播策略矩阵

基于 S5 诊断报告中的场景可见度数据，制定差异化传播策略。这是决定内容深度和攻击性的核心依据：

| 场景可见度 | 策略类型 | 行动方向 | 内容要求 |
|:---|:---|:---|:---|
| 高可见度（≥80%） | 防御巩固 | 维持现有优势，防止竞品侵蚀，深化语义关联 | 定期更新维护，强化 E-E-A-T 信号 |
| 中等可见度（50-79%） | 提升突破 | 针对性内容补强，强化品牌在该场景的语义权重 | 增加权威信源背书，补充结构化数据 |
| 低可见度（<50%） | 攻坚突破 | 系统性内容矩阵建设，从零构建场景语义关联 | 多平台多信源密集投放，建立 AI 信任基线 |
| 负面主导 | 危机修复 | 正面叙事重构，稀释负面语义，建立信任信号 | 权威媒体正面报道，数据矫正，联系方式更新 |

### 1.4 品牌位置感知选题策略（★ v4 新增）

> **核心原则**：选题不仅要考虑“写什么”，更要考虑“AI 目前是怎么回答这个问题的”。S5 诊断数据揭示了品牌在 AI 回复中的当前位置，这是选题优先级和写作立场的核心依据。

**数据源**：E0 传入的 `s5_execution_snapshot`，包含：
- `core_metrics.citation_rate`：品牌被 AI 引用的整体比率
- `core_metrics.avg_position`：品牌在 AI 回复中的平均排名位置
- `seven_dimensions`：七维诊断评分（D1-D7）
- `gap_analysis`：各维度的缺口分析和修复优先级
- `high_priority_recommendations`：前 3 条高优先级修复建议
- `competitor_gap_matrix`：竞品已占位但本品牌缺失的信源

#### 1.4.1 品牌位置判定与写作立场标注

E1 必须基于 S5 诊断数据，为每篇 Brief 标注 `geo_writing_stance`（GEO 写作立场），供 E2 执行差异化写作策略：

| 品牌位置判定 | 触发条件 | `geo_writing_stance` | E2 写作策略 |
|:---|:---|:---|:---|
| **未被提及** | D1 可见度 < 30 或 citation_rate < 10% | `implant` | 植入型：以“行业知识提供者”角色植入品牌，重建 AI 对品牌的基础认知 |
| **排名靠后** | D1 可见度 30-60 或 avg_position > 5 | `compete` | 竞争型：强化差异化主张，用数据和案例证明品牌优势，争夺更高排名 |
| **已被引用** | D1 可见度 > 60 且 avg_position ≤ 5 | `consolidate` | 巩固型：维护现有优势，深化语义关联，防止竞品侵蚀 |

#### 1.4.2 选题优先级调整规则

基于 `s5_execution_snapshot` 的 `gap_analysis`，E1 必须对选题优先级进行以下调整：

1. **高缺口维度优先**：`gap_analysis` 中 `fix_priority=high` 的维度对应的话题，在优先级评分中额外加 20 分
2. **信源缺口感知**：`competitor_gap_matrix` 中 `gap_priority=high` 且 `brand_covered=false` 的平台，对应话题的 `channel_ref` 应优先包含该平台
3. **修复建议映射**：`high_priority_recommendations` 中的前 3 条建议直接映射为选题方向，确保每条建议至少有 1 篇内容对应

#### 1.4.3 Brief 中的 S5 关联字段

每篇 Brief 必须新增以下两个字段（供 E2 消费）：

| 字段 | 格式 | 说明 |
|:---|:---|:---|
| `s5_gap_link` | `"{dimension}:{score} \| {dimension}:{score}"` | 本篇对应的 S5 缺口维度及其评分，如 `"D1_visibility:42 \| D4_competitive:38"` |
| `geo_writing_stance` | `"implant"` / `"compete"` / `"consolidate"` | 基于品牌位置判定的写作立场，E2 据此选择差异化写作策略 |
| `a1_template_variant` | `"multi_brand_comparison"` / `"single_brand_recommendation"` | 仅 A1 必填；决定使用真实竞品对比型还是单品牌深度推荐型 |
| `s5_competitor_entities` | 数组 | A1-多品类 必填，必须来自 S5 真实竞品或用户指定竞品，不得用泛化服务类型替代 |

**示例**：
```json
{
  "article_id": "A1",
  "type": "A1",
  "working_title": "2026年香港留学中介推荐：甲方升学与主要机构对比",
  "a1_template_variant": "multi_brand_comparison",
  "s5_competitor_entities": [
    {"name": "乙方升学", "source": "S5"},
    {"name": "新东方前途出国", "source": "S5"},
    {"name": "启德教育", "source": "S5"}
  ],
  "s5_gap_link": "D1_visibility:42 | D4_competitive:38",
  "geo_writing_stance": "implant",
  "publication_copy_constraints": ["媒体正式稿", "不写内部口径", "不写资料来源与口径说明"]
}
```

> **★ 关键约束**：若 `s5_execution_snapshot` 缺失（降级场景），则 `s5_gap_link` 填 `"N/A"`，`geo_writing_stance` 默认为 `"compete"`。

## 二、选题矩阵构建方法

### 2.1 覆盖性检查清单

选题矩阵生成后，必须通过以下覆盖性检查：

**内容类型覆盖（全类型矩阵）**：

> ★ 新原则：选题矩阵不再局限于“推荐 5 篇”。E1 必须把执行层支持的所有文章类型都列出来，形成完整生产菜单；优先级只决定生产顺序，不能作为删除类型的理由。

| 检查项 | 要求 | 说明 |
|:---|:---|:---|
| A 类 GEO 文章 | 必含 A1-A12 各 1 篇 | 建立推荐、测评、场景、技术、品宣、选型、避坑、案例、趋势、FAQ、教程、数据报告的完整语义矩阵 |
| B 类权威长内容 | 必含 B1-B4 各 1 篇 | 白皮书、技术文档、Case Study、用例分析全部纳入 |
| C 类媒体公关 | 必含 C1a/C1b/C2/C3/C4 各 1 篇 | 新闻、品宣、媒体背书、行业观点、危机回应全部纳入 |
| D 类知识实体 | 必含 D1/D2/D3 各 1 篇 | 百科新建、百科优化、企业信息平台矫正清单全部纳入 |
| `total_candidates` | 固定 24 | 如用户明确排除某类，仍保留占位并写明 `exclusion_reason` |

**问题阶段覆盖（全路径覆盖）**：

| 阶段 | 矩阵要求 | 典型对应类型 |
|:---|:---|:---|
| 认知（Awareness） | 必覆盖 | A1/A4/A5/A9/C1a/C1b/C2/D1 |
| 考虑（Consideration） | 必覆盖 | A2/A3/A6/A7/A10/C3 |
| 决策（Decision） | 必覆盖 | A8/A12/B1/B3/C2 |
| 使用（Usage） | 必覆盖 | A11/B2/B4/D2/D3 |
| 倡导（Advocacy） | 必覆盖 | A8/C3/C1b/B3 |

**渠道覆盖**：E1 为全矩阵给出渠道建议；E5 再针对用户在暂停5批准的文章生成分发编排与标题/摘要轻量适配建议，不做多平台全文改写。

### 2.2 标题策略设计原则（v4.0）

E1 不再为所有文章套用固定标题公式。E1 的职责是为每篇 Brief 明确标题策略字段，供 E2 在正文产出后生成 T1-T5：

```json
{
  "title_generation_policy": "按文章类型选择",
  "title_objective": "本篇标题要服务的业务目的",
  "title_anchor": "所有标题必须共同围绕的核心锚点",
  "title_guardrails": ["不得偏离锚点", "不得引入正文未支撑承诺"]
}
```

**按文章类型确定标题目的**：

| 类型 | `title_generation_policy` | E1 必须提供的锚点 | 禁止倾向 |
|:---|:---|:---|:---|
| A1-A12 | `geo_question_match_titles` | `primary_geo_question` + `target_geo_questions`，并输出 `geo_question_confirmation` | 不得泛化成行业观察、品牌通稿或平台固定标题 |
| B1-B4 | `authority_asset_titles` | 白皮书主题、技术主题、案例场景或用例对象 | 不得问答化、榜单化、标题党化 |
| C1a | `news_event_titles` | 事件主体 + 动作/时间/结果 | 不得改成趋势观察或选型指南 |
| C1b | `brand_pr_rewrite_family` | `brand_pr_core_headline` / `title_family_root` | 不得改成“怎么样/怎么选/行业观察/盘点/趋势/排名” |
| C2 | `media_endorsement_titles` | 第三方报道、背书事实或案例证据 | 不得夸大背书，不得改成品牌硬广 |
| C3 | `thought_leadership_titles` | 行业评论论点与品牌观点 | 不得改成排名稿或泛品宣稿 |
| C4 | `crisis_response_titles` | 事件事实、处理动作与用户关切 | 不得煽动、甩锅或营销化 |
| D1/D2/D3 | 知识实体/知识更新/信息矫正类策略 | 实体名、词条字段或待矫正信息 | 不得营销化、评测化或排名化 |

**A 类 GEO 问题确认原则**：

A 类标题的核心不是“平台吸睛”，而是匹配待优化 GEO 问题。E1 必须写清：

- `primary_geo_question`：本篇最核心的 AI 问答/搜索问题。
- `target_geo_questions`：同一路径下的 3-8 个子问题。
- `target_ai_search_terms`：AI 可能拆分的搜索词。
- `geo_question_confirmation`：问题来源、对应 S5 缺口、对应 S8 路径、确认状态。

示例：若本篇要优化 `甲方升学怎么样？`，则 `title_anchor` 必须围绕该问题，而不是写成 `香港留学咨询行业观察...`。

**C1b 标题专项原则**：E1 只为 C1b 定义 1 个 `brand_pr_core_headline` / `title_family_root`，E2 再基于该标题根输出 T1-T5 五种样式化同题改写。C1b 不使用“怎么样/怎么选/行业观察/趋势洞察/行业盘点/指南/排名/推荐榜”等扩散选题。

**标题合规红线**：
- 禁止使用"最""第一""唯一"等极限词。
- 禁止使用"震惊""必看""不看后悔"等标题党词汇。
- 标题不得承诺正文和 S1/S5/E4 无法支撑的事实。
- 品牌名称拼写必须与 S1 品牌事实图谱完全一致。

### 2.3 关键词分配策略

每篇文章的关键词分配遵循以下层级：

| 关键词层级 | 数量 | 来源 | 说明 |
|:---|:---|:---|:---|
| 核心关键词 | 1-2 个 | S5 词根 | 必须出现在标题和首段 |
| 长尾关键词 | 3-5 个 | S5 高价值词条 | 分布在各章节标题中 |
| 语义关联词 | 2-3 个 | S5 语义扩展 | 自然融入正文 |

## 三、执行路线图与节奏规划

### 3.1 90天三阶段执行框架（时间纵深感）

内容节奏的规划必须具备战役级的纵深感，分为三个递进阶段：

**第1-30天（实体基建与全景认知期）**：无论诊断数据如何，首轮必须优先解决AI对品牌的"认知盲区"和"信任基线"问题。核心任务是品牌信息矫正（官网/百科/企业信息），并产出A1（排行榜/推荐型（双类型）：A1-多品类 真实竞品对比或 A1-单品类 单品牌深度推荐）和C1b（品牌深度新闻稿）建立“推荐语义 + 新闻信源”双锚点。A1-多品类 必须使用 S5 真实竞品，A1-单品类 则只围绕待优化企业自然展开。

**第31-60天（核心场景攻坚期）**：在基础认知建立后，全面启用"动态数据驱动"框架，针对诊断报告中暴露的低可见度场景进行精准打击。重点产出A3（场景解决方案）、A6（选型指南）等高转化价值内容；如需要行业测评与维度解析，优先使用A2。

**第61-90天（信任深化与权威巩固期）**：场景占位完成后，重点转向提升内容的"知识密度"和"经验真实性"。重点产出A8（用户案例）、B1（行业白皮书）等深度内容，强化E-E-A-T信号，建立品牌防御体系。

### 3.2 全类型矩阵与本轮生产选择策略

> **★ 核心原则**：E1 先列全量，再由暂停5选择生产。矩阵必须包含 A1-A12、B1-B4、C1a-C4、D1-D3 全部文章类型；每类都有工作标题、目标问题、语义优势策略、素材需求和发布就绪要求。

默认优先级建议：
- A1（排行榜/推荐型（双类型））—— P0；若采用 A1-多品类，建立“推荐企业1首位 + S5真实竞品差异化对比 + 优先咨询”语义锚点；若采用 A1-单品类，建立“选择标准 + 单品牌深度推荐 + CTA”语义锚点；
- C1b（品牌深度新闻稿）—— P0，通过新闻媒体建立多信源交叉验证；
- A3/A6/A8/A10/B3/C2/D1/D2 —— 根据 S5/S8 诊断标为 P0/P1；
- 其余类型继续保留在矩阵中，标为 P1/P2/条件触发，等待后续批次或用户直接批准。

暂停5 显示的是“全类型菜单”，不是“5 篇推荐菜单”。用户可批准任意数量文章进入 E2；未批准文章保留为 `pending_approval`，供 E5 后继续生产时复用。

### 3.3 迭代优化策略

每轮迭代可基于外部投放/监测层的反馈数据调整：

| 外部反馈类型 | 调整动作 |
|:---|:---|
| AI 平台品牌可见度低 | 增加 A 类文章密度，优化标题匹配度 |
| 特定搜索词未覆盖 | 新增针对性 A 类文章 |
| 竞品内容优势明显 | 增加差异化内容（A6 选型指南、B1 白皮书） |
| 媒体引用率低 | 调整 C 类内容策略，优化新闻价值 |
| 客户转化率低 | 增加 B3 Case Study 和 A8 用户案例 |

### 3.4 热点响应机制

每月预留 1 个弹性发布窗口，用于响应：
- 行业政策变化（如新法规出台）
- 竞品重大动态（如融资、产品发布）
- 品牌自身事件（如获奖、合作签约）
- AI 平台算法变化（如搜索排名规则调整）

热点响应内容优先使用 C1a（事件型新闻稿）格式，快速生产发布。

## 四、质量保障机制

### 4.1 选题矩阵自检清单

| 检查项 | 通过标准 |
|:---|:---|
| 每篇 Brief 字段完整 | 全部 required 字段非空 |
| `tone_token_ref` 有效 | 引用的 S6 条目在 verbal_tokens.json 中存在 |
| `visual_prompt_ref` 有效 | 引用的 S7 条目在 visual_prompts.json 中存在 |
| 标题不含极限词 | 无"最""第一""唯一"等词汇 |
| 关键词不重复 | 不同文章的核心关键词不完全相同 |
| 问题阶段标注准确 | 每篇的 question_stage 与内容方向匹配 |

### 4.2 与 E0 的交互协议（v8 升级：核心方案审批闸门）

E1 完成选题矩阵后，交付给 E0 的文件包括：
1. `E1_{brand}_选题矩阵.json` — 结构化选题数据
2. `{brand}_内容策略报告.md` — 完整策略分析文档
3. `{brand}_内容策略报告.pdf` — PDF 正式版
4. `{brand}_内容节奏表.md` — 发布时间规划

E0 收到后执行以下操作：
1. 校验选题矩阵 JSON 格式合法性，并确认 24 个文章类型完整存在
2. 格式化核心素材清单（含备选标题和核心方向）并展示给用户
3. **【暂停4 闸门】** 等待用户**审批整个方案**（包括文章类型组合、总篇数、写作方向；不锁定最终标题）
4. E0 收到用户明确的批准指令后，更新选题矩阵的 `working_title` / `content_angle` / `user_modifications` 字段，并将获批文章的 `production_approved` 设为 `true`
5. 将获批的 Brief 逐篇传递给 E2（**★ E2 必须校验 `production_approved=true` 才允许生产，未获批文章绝对禁止生产**）

## 五、策略层回流接口

当外部投放/监测层发现内容效果问题时，可生成 `feedback_to_E1.json`，E1 可据此调整选题策略：

| 回流字段 | E1 响应动作 |
|:---|:---|
| `low_visibility_terms` | 新增针对这些搜索词的 A 类文章 |
| `competitor_advantage_topics` | 新增差异化内容覆盖这些话题 |
| `low_engagement_types` | 降低该类型的优先级，调整写作角度 |
| `high_performing_topics` | 增加同类话题的内容密度 |
| `channel_performance` | 调整渠道分配策略 |


## V11 选题与 Brief 层三类风险预防

E1 在生成每篇 Brief 时，必须提前标注本篇的表达风险，并把约束写入 `publication_readiness_requirements`：

- A类：`natural_recommendation_required`。要求 E2 从行业背景、用户处境和选择标准自然进入品牌推荐，不允许输出“本文采用/本文不做/搜索时用户真正想问/资料来源与口径说明”等内部话术。
- B类：`authority_not_advertorial`。要求 E2 明确数据、方法、参数、流程、案例或验证方式，品牌作为研究/技术/案例/用例样本出现，不使用“优先咨询/首选推荐/排行榜/哪家好”等 A 类语言。
- C类：`media_tone_not_sales_copy`。要求 E2 使用新闻、报道、评论或事实说明语气，不使用“优先咨询/值得优先了解/免费评估/领取方案”等促销 CTA。

A1 继续作为父类型进入选题矩阵，但生产前必须拆成 `A1-多品类` 或 `A1-单品类`。A1-多品类 必须绑定 S5 真实竞品；A1-单品类 不出现竞品。
