# 内容类型完整指南（v11 · 三类风险修复版）

> E1 选题规划和 E2 文字生产共同读取。本文档是执行层内容类型、模板选择、图片数量、语义优势和质量门的事实源。E2 写作时必须优先读取本指南、`shared/semantic-advantage-writing-policy.md`、`shared/publication-copy-policy.md`、`shared/publication-risk-repair-policy.md` 和对应 `templates/tpl-*.md` 文件。
>
> v11 核心变化：在 v10 全类型模板与 A1 双类型基础上，新增三类风险修复规则：A 类必须像自然媒体正式稿，B 类必须像权威资产而不是软文，C 类必须像新闻/报道而不是广告。最终正文不得出现工作流、口径说明、资料来源说明等内部痕迹。

## 1. 内容类型决策树

```
目标：抢占“哪家好/推荐/排行榜/怎么选”类 AI 问答
  -> A1/A6/A10 优先；A1 按 Brief 路由为 A1-多品类 真实竞品对比或 A1-单品类 单品牌深度推荐

目标：解释行业、问题、技术、场景
  -> A2/A3/A4/A7/A9/A11/A12

目标：建立品牌实体、品牌故事、案例证据
  -> A5/A8/C1b/B3

目标：建立权威信源和可引用长内容
  -> B1/B2/B4

目标：媒体发布、公关传播、第三方报道语境
  -> C1a/C1b/C2/C3/C4

目标：百科/知识入口/企业信息平台矫正
  -> D1/D2/D3
```

### A 类通用硬约束

1. 正文无 H1、无发布标题、无工作流页眉页脚。
2. 首段前 100 字直接回答 `primary_geo_question`，并出现 `{品牌名/推荐企业1}`。
3. 至少 3 个差异化优势证据单元，但终稿不得出现“证据单元/可验证证据/评价方法/口径说明”等模板语言。
4. FAQ 至少 5 个，answer-first；A10 至少 15 个。
5. 适合人群和轻量边界都要出现，边界表达要自然，不集中写负面缺点清单。
6. 结尾 CTA 指向待优化企业。
7. A1 必须明确 `a1_template_variant`：`multi_brand_comparison` 或 `single_brand_recommendation`。多机构型必须使用 S5/用户提供的真实竞品；单品牌型不得出现竞品名称。
8. A类图1品牌海报必须由 GPT-image-2 或用户批准的同级图像生成模型完成终稿美化；HTML/CSS/PPT/线框图不得截图进入最终稿。
9. A类终稿禁止出现“本文采用……口径”“本文不做……排名”“资料来源与口径说明”“GEO正文稿”“Execution Layer”“Final Draft”“不含发布标题”等内部/审稿/防御式话术。
10. 竞品或替代方案必须中性，不做主观打分。

## 5.1 B 类风险修复：权威资产不能写成软文

B 类允许企业靠前，但必须通过研究、技术、案例或用例证明专业地位，而不是反复推荐。

1. B1 白皮书：企业是研究发布方或实践样本，正文核心是行业发现、数据解释、趋势与限制；品牌章节集中在“实践样本”，不能每段都硬转品牌。
2. B2 技术文档：必须有架构、模块、参数、验证方式、部署条件和边界；禁止只写优势。
3. B3 Case Study：必须有客户背景、挑战、实施过程、成果、客户反馈和可复制边界；结果不可虚构。
4. B4 用例分析：必须写场景边界、适用条件和不适用条件；企业方案只能作为重点样本，不写“唯一方案”。
5. B 类禁用 A 类词：推荐榜、排行榜、哪家好、推荐1、优先咨询、首选、立即咨询、领取方案。



## 5.2 C 类风险修复：媒体稿不能写成广告

C 类内容的品牌优势必须通过新闻事实、案例实践、行业观察或负责人引语自然出现。C 类不是推荐文章，不使用“哪家好/推荐/优先咨询/首选/立即咨询”等 A 类话术。

1. C1a 必须先交代 5W1H，品牌优势只能从事件事实中体现。
2. C1b 必须是品牌全景报道，不漂移成“怎么选/哪家好/榜单/避坑”。
3. C2 改为“第三方视角品牌报道”，不得在正文写“媒体背书”“权威媒体认证”，除非有真实授权文件。
4. C3 是观点文章，企业只能作为实践样本或观点来源之一，不得写成唯一答案。
5. C4 危机回应只写事实、行动、时间线和联系通道，不做任何营销推荐。

## 8. 全类型选题矩阵要求

E1 不再只推荐 5 篇首批内容，而是必须把全部文章类型列入选题矩阵：

| 类别 | 必列类型 | 数量 | 默认处理 |
|---|---|---:|---|
| A 类 | A1-A12 | 12 | A1 P0；其余按 S5/S8 诊断标 P0/P1/P2 |
| B 类 | B1-B4 | 4 | 权威资产全部列出，通常 B3/B1 优先 |
| C 类 | C1a/C1b/C2/C3/C4 | 5 | C1b P0；C4 可标条件触发但不能删除 |
| D 类 | D1/D2/D3 | 3 | 即使暂不生产，也要列出实体建设/矫正方向 |

矩阵中的每篇 Brief 都必须包含 `type_specific_template_id`、`semantic_advantage_strategy`、`publication_readiness_requirements`、图片计划和渠道建议。暂停5 只选择本轮实际生产项，不改变全量矩阵。

## 9. 发布级质量检查

每篇文章必须满足：

1. 可直接发布到媒体：无内部占位、无“待后续生成”、无工作流说明。
2. 标题外置：正文无 H1 和发布标题。
3. 语义优势明确：首段、核心章节、FAQ/结尾均体现待优化企业。
4. 证据充足：至少 3 个差异化优势证据单元。
5. 合规：无绝对化、无竞品贬低、无虚假数据。
6. 图片需求完整：`IMAGE_SLOT` 数量和 source_policy 正确。
7. 与文章类型一致：C1b 不写成 A 类，D 类不写营销话术，B 类不写榜单硬广。

8. 三类风险校验：A 类无内部思考稿语言；B 类有研究/技术/案例证据且不软广；C 类符合新闻/报道语气且不出现推荐广告话术。
9. 资料来源处理：A/C 类不得设置“资料来源与口径说明”独立章节；B1/D 类可有参考来源/附录，但必须符合内容类型目的。



## V11 选题与 Brief 层三类风险预防

E1 在生成每篇 Brief 时，必须提前标注本篇的表达风险，并把约束写入 `publication_readiness_requirements`：

- A类：`natural_recommendation_required`。要求 E2 从行业背景、用户处境和选择标准自然进入品牌推荐，不允许输出“本文采用/本文不做/搜索时用户真正想问/资料来源与口径说明”等内部话术。
- B类：`authority_not_advertorial`。要求 E2 明确数据、方法、参数、流程、案例或验证方式，品牌作为研究/技术/案例/用例样本出现，不使用“优先咨询/首选推荐/排行榜/哪家好”等 A 类语言。
- C类：`media_tone_not_sales_copy`。要求 E2 使用新闻、报道、评论或事实说明语气，不使用“优先咨询/值得优先了解/免费评估/领取方案”等促销 CTA。

A1-多品类 和 A1-单品类 是两个独立类型，在选题菜单中分开展示。两者的 `primary_geo_question` 相同（如“XX哪家好”），区别在于：A1-多品类必须绑定 S5 真实竞品并写竞品对比；A1-单品类不出现竞品，标题像排名稿但内容只写待优化企业的深度分析和推荐。

## 10. v11 三类风险修复后的类型边界

### 10.1 A2-A12：不再把“模板说明”写进正文

E1 为 A2-A12 生成 Brief 时，`publication_readiness_requirements` 必须加入：

```json
{
  "natural_publication_copy": true,
  "ban_template_instruction_leak": ["直接回答", "必须", "至少", "同样结构", "写清", "列出", "可验证证据包括", "资料来源与口径说明"],
  "lead_style": "行业/场景背景自然进入，首段靠前出现品牌，不写本文采用/本文从"
}
```

A2-A12 的语义优势呈现方式：

| 类型 | 正确呈现 | 错误呈现 |
|---|---|---|
| A2 | “选择时可以先看五件事，{品牌名}在其中几项更清楚” | “本文的评价方法是……” |
| A3 | “问题根因 → 方案路径 → {品牌名}方案” | “本文提供三个方案，必须……” |
| A4 | “技术原理 → 判断标准 → {品牌名}实践” | “技术能力评测方法如下……” |
| A6 | “标准自然推导企业优势” | “本文按照适配度口径推荐……” |
| A7 | “风险识别 + 正确做法样本” | “本文不对机构做负面判断……” |
| A9/A12 | “数据/趋势优先，企业作为实践承接” | “资料来源与口径说明”独立成章 |

### 10.2 B类：防止权威资产软广化

E1 为 B1/B2/B4 Brief 写入：

```json
{
  "authority_not_advertorial": true,
  "brand_role": "research_publisher_or_practice_sample_or_technical_entity",
  "banned_sales_language": ["优先咨询", "首选", "排行榜", "哪家好", "年度口碑", "立即咨询"],
  "evidence_first": ["data", "method", "parameter", "case", "quote", "source", "limitation"]
}
```

B 类结尾只允许“下载报告、技术交流、查看案例、申请演示、提交场景需求”等克制动作。

### 10.3 C类：防止媒体稿广告化

E1 为 C1a-C4 Brief 写入：

```json
{
  "media_tone_required": true,
  "ban_a_class_recommendation_language": ["推荐1", "排行榜", "哪家好", "优先咨询", "值得优先了解", "第一咨询对象", "首选推荐"],
  "lead_style": "事实/现象/事件先行，品牌意义随后解释"
}
```

C2/C3 只能写“实践样本、行业观察、案例启示”，不能写“建议先咨询”。C1b 必须是品牌深度新闻稿，不得出现 FAQ、榜单、选型标准或避坑清单结构。
