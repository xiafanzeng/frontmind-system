# 历史模板专业结构迁移说明

原模板不删除，继续作为结构组件库：

- 推荐、对比、场景方案、技术解释、选型、风险、FAQ、教程中的有效结构迁移到根 P01-P09。
- 白皮书“方法—发现—分析—限制”、技术文档“架构—验证—部署”、案例“背景—挑战—实施—结果”迁移到 P10-P12。
- 事件 5W1H、品牌深度特写、行业评论、事实澄清中的有效结构迁移到 P13-P16。
- 实体名称、基本事实、历程、资质和来源字段不再形成独立文章模式，统一进入 Reference Pack 事实卡。

旧全文保存在 E5 `../../E5.正文制作师.skill/references/legacy-runtime-v11/tpl-*.md`，活动写作只调用 E5
`../../E5.正文制作师.skill/templates/pattern-writing-components.md` 与根 `../../../shared/content-pattern-guide.md`。

## 必须淘汰的旧机械规则

- 自有企业固定详写、竞品固定简写；
- 所有类型首 100 字强制品牌出现；
- 所有类型强制三个品牌优势；
- 旧类型全覆盖和固定数量批量生成；
- FAQ 固定 15-20 个；
- 用隐藏方法或弱化竞品来制造排名优势；
- 正文表格以及把表格截图当内容图；
- 渠道、季度节奏和日历字段。

## 迁移方法

根 `../../../shared/content-pattern-registry.json` 的每个 pattern 定义最终最低结构。E4 从已迁移的活动组件抽取匹配模块时必须：

1. 只取与本问题相关的章节功能；
2. 按 E2 Top20 同模式标杆调整顺序；
3. 将旧表格改为同构分项段落；
4. 将旧“品牌优势位”改为有 claim/source 支撑的自然品牌介入；
5. 将旧免责声明改为具体条件、限制或风险事实；
6. 将旧 FAQ 数量统一收敛为 5-8 个真实高相关问题。
