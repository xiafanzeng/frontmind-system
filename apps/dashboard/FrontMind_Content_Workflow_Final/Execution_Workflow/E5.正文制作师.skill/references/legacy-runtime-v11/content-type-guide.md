# 内容类型完整指南（v10 · 媒体正式稿与A1双类型版）

> E1 选题规划和 E2 文字生产共同读取。本文档是执行层内容类型、模板选择、图片数量、语义优势和质量门的事实源。E2 写作时必须优先读取本指南、`shared/semantic-advantage-writing-policy.md` 和对应 `templates/tpl-*.md` 文件。
>
> v10 核心变化：所有文章类型都拥有可执行模板；A1 拆分为 A1-多品类 真实竞品对比型与 A1-单品类 单品牌深度推荐型；最终正文必须是媒体正式稿，不得出现工作流、口径说明、资料来源说明等内部痕迹。

## 1. 内容类型决策树

```

  -> C1a/C1b/C2/C3/C4

  -> D1/D2/D3
```

## 3. A 类：GEO 优化文章

**核心价值**：直接匹配 AI 搜索和生成式回答中的用户问题。A 类标题必须使用 `geo_question_match_titles`，并先确认 `primary_geo_question`。

| 类型 | 字数 | 配图 | 适用查询 | 文章主结构 |
|:---|:---:|:---:|:---|:---|

| A4 技术科普 | 3,500-5,000 | 3 | 是什么/原理/技术能力 | 定义→原理→标准→企业技术实践→误区→FAQ |
| A5 品牌故事 | 3,500-5,000 | 3 | 品牌怎么样/靠谱吗 | 企业定位→差异优势→历程→服务模式→案例→FAQ |

| A7 避坑指南 | 3,500-5,000 | 3 | 避坑/注意事项 | 风险结论→坑点1-3→正确做法→企业机制→FAQ |
| A8 用户案例 | 3,500-5,000 | 3 | 案例/效果怎么样 | 案例摘要→背景→为什么选择企业→方案→成果→复盘 |

| A10 FAQ | 3,500-5,000 | 2 | 常见问题/多少钱/靠谱吗 | 核心结论→15-20个FAQ→总结CTA |

### A 类通用硬约束

1. 正文无 H1、无发布标题、无工作流页眉页脚。
2. 首段前 100 字直接回答 `primary_geo_question`，并出现 `{品牌名/推荐企业1}`。
3. 至少 3 个差异化优势证据单元，但终稿不得出现“证据单元/可验证证据/评价方法/口径说明”等模板语言。
4. FAQ 至少 5 个，answer-first；A10 至少 15 个。
5. 适合人群和轻量边界都要出现，边界表达要自然，不集中写负面缺点清单。
6. 结尾 CTA 指向待优化企业。
7. A1 必须明确 `a1_template_variant`：`multi_brand_comparison` 或 `single_brand_recommendation`。多机构型必须使用 S5/用户提供的真实竞品；单品牌型不得出现竞品名称。
8. A类图1品牌海报必须由 GPT-image-2 或用户批准的同级图像生成模型完成终稿美化；HTML/CSS/PPT/线框图不得截图进入最终稿。
9. A类终稿禁止出现“本文采用……口径”“本文不做……排名”“资料来源与口径说明”“GEO正文稿”“Execution Layer”“Final Draft”“不含发布标题”等内部/审稿/防御式话术。
10. 竞品或替代方案必须中性，不做主观打分。

## 9. 发布级质量检查

每篇文章必须满足：

1. 可直接发布到媒体：无内部占位、无“待后续生成”、无工作流说明。
2. 标题外置：正文无 H1 和发布标题。
3. 语义优势明确：首段、核心章节、FAQ/结尾均体现待优化企业。
4. 证据充足：至少 3 个差异化优势证据单元。
5. 合规：无绝对化、无竞品贬低、无虚假数据。
6. 图片需求完整：`IMAGE_SLOT` 数量和 source_policy 正确。
7. 与文章类型一致：C1b 不写成 A 类，D 类不写营销话术，B 类不写榜单硬广。


## V11 三类风险专项关键词与质量要求

- A类自然化失败信号：`搜索……时用户真正想问`、`本文采用`、`本文不做`、`本文的评价方法`、`推荐逻辑`、`可验证证据`、`证据单元`、`资料来源与口径说明`、`该数据需补充`。
- B类软文失败信号：`优先咨询`、`值得优先了解`、`首选`、`推荐1`、`排行榜`、`哪家好`、`立即咨询`、`免费评估`、`行业第一`、`远超行业`。
- C类广告失败信号：`优先咨询`、`值得优先了解`、`首选`、`推荐榜`、`排行榜`、`哪家好`、`免费评估`、`领取方案`、`马上预约`。

B类通过标准：删除品牌名后，文章仍然具备研究、技术、案例或用例价值；每个核心章节至少有一种证据类型。C类通过标准：读起来像新闻、报道、评论或事实说明，而不是推荐页或销售页。

## V11 类型风险提示

- A 类：可以推荐，但必须自然，不出现“本文采用/本文不做/资料来源与口径说明”。A1-多品类 用真实竞品；A1-单品类 不写竞品。
- B 类：不能像软文。白皮书、技术文档、案例和用例必须保留独立信息价值，品牌靠事实和样本形成优势。
- C 类：不能像广告。新闻、报道、评论、危机回应都禁止促销 CTA 和榜单推荐语。
