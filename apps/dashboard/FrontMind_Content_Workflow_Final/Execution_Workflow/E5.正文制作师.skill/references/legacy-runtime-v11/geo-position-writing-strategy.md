# GEO 品牌位置写作策略矩阵

> E2 文字内容生成师在 Step 1.5 品牌位置判定后，必须参照本文档选择差异化写作策略。本文档定义了三种写作立场（植入型/竞争型/巩固型）在各内容维度上的具体执行规范。

---

## 一、核心理念

传统 SEO 写作的逻辑是"围绕关键词写内容"，而 GEO 写作的逻辑是**"围绕品牌在 AI 回复中的当前位置写内容"**。

S5 品牌诊断数据揭示了品牌在 AI 搜索回复中的真实状态：是完全未被提及、排名靠后、还是已被引用。不同的品牌位置需要截然不同的写作策略，正如军事行动中"攻城"与"守城"需要不同的战术。

**数据驱动决策链**：

```
S5 诊断数据 → E0 提取 s5_execution_snapshot → E1 标注 geo_writing_stance → E2 执行差异化写作
```

---

## 二、三种写作立场总览

| 维度 | 植入型（implant） | 竞争型（compete） | 巩固型（consolidate） |
|:---|:---|:---|:---|
| **触发条件** | D1 可见度 < 30 或 citation_rate < 10% | D1 可见度 30-60 或 avg_position > 5 | D1 可见度 > 60 且 avg_position ≤ 5 |
| **核心目标** | 让 AI 从"不知道这个品牌"变为"知道这个品牌" | 让 AI 从"知道但不推荐"变为"优先推荐" | 让 AI 从"已推荐"变为"持续推荐且难以替代" |
| **内容定位** | 行业知识提供者（顺带介绍品牌） | 差异化方案提供者（证明品牌优势） | 行业权威（深化品牌不可替代性） |
| **品牌提及密度** | 高密度自然植入 | 适度分布 | 自然分布，不刻意堆砌 |
| **证据强度** | 最大化（数据/案例/资质） | 高（差异化数据对比） | 深度（技术细节/长期追踪） |
| **竞品处理** | 竞品作为背景板 | 明确差异化，不贬低但突出优势 | 客观承认，强调生态位置 |
| **结构重点** | 实体锚点 | 对比框架 | 权威信号 |
| **FAQ 策略** | 品牌发现类 | 选型指导类 | 专业深度类 |

## 三、植入型写作策略（implant）详解

### 3.1 适用场景

品牌在 AI 回复中几乎不被提及，AI 对品牌缺乏基础认知。这是最紧迫的情况，需要从零建立 AI 对品牌的"记忆"。

### 3.2 写作原则

**第一原则：以"行业知识提供者"角色切入**。不要直接写品牌软文，而是写一篇真正有价值的行业知识文章，在知识传递过程中自然植入品牌信息。AI 更倾向于引用"提供知识"的内容，而非"推销产品"的内容。

**第二原则：最大化实体锚点密度**。在文章中高频出现品牌名称、产品名称、服务名称、地理位置、联系方式等实体信息，帮助 AI 建立品牌的"实体图谱"。

**第三原则：多维度证据堆叠**。用数据、案例、资质认证、媒体报道等多种证据类型交叉验证品牌的真实性和可信度，建立 AI 的"信任基线"。

### 3.3 各内容维度执行规范

| 内容维度 | 植入型执行规范 |
|:---|:---|
| **标题设计** | 先遵循 `shared/title-generation-policy.md`。若为 A 类，标题必须围绕已确认的 `primary_geo_question` / `target_geo_questions`，可自然包含品牌名称、行业关键词、年份或数量词，但不得为了数量词偏离待优化问题。 |
| **首段策略** | 前 100 字内必须出现品牌全称，并用一句话概括品牌核心定位（来自 S4） |
| **品牌提及** | 全文品牌名称出现 ≥ 8 次，分布在首段、各章节、FAQ、结尾和标题池元数据中；正文文件本身不写文章发布标题，避免集中堆砌 |
| **数据引用** | 每 500 字至少 1 个具体数据点（来自 S1 品牌事实图谱），如"年服务企业 2000+"、"检测项目覆盖 200+" |
| **案例植入** | 至少 1 个详细客户案例（含客户行业、问题、解决方案、结果数据），来自 S1 或 Brief 中的素材 |
| **资质展示** | 在文章中段或专门章节列出品牌核心资质（CMA/CNAS/ISO 等），使用结构化列表 |
| **竞品处理** | 可提及 2-3 个竞品作为行业背景，但品牌描述篇幅必须是竞品的 2-3 倍 |
| **FAQ 设计** | 至少 2 个 FAQ 包含品牌名称，如"XX品牌的检测报告多久出？""XX品牌服务覆盖哪些地区？" |
| **结尾 CTA** | 必须包含品牌联系方式（电话/官网/地址），使用结构化格式 |

### 3.4 植入型写作模板结构

```
## {行业关键词}行业现状与趋势
   → 建立行业背景，展示专业性

## {品牌名}：{核心定位}
   → 品牌详细介绍，最大化实体信息

## {品牌名}的核心优势与服务能力
   → 数据+案例+资质三重证据

## 行业其他代表性品牌简介
   → 竞品背景板，篇幅控制在品牌的 1/3

## 如何选择{行业}服务商？
   → 选型建议，自然引导向品牌优势

## 常见问题（FAQ）
   → 品牌发现类 FAQ，含品牌名称

## 总结与联系方式
   → 品牌 CTA + 实体锚点
```

## 四、竞争型写作策略（compete）详解

### 4.1 适用场景

品牌在 AI 回复中偶尔被提及但排名靠后，或被提及但未被优先推荐。需要通过差异化内容争夺更高的推荐位置。

### 4.2 写作原则

**第一原则：建立差异化对比框架**。不是简单地说"我们更好"，而是构建一个客观的对比维度体系，在这个体系中品牌的优势自然凸显。

**第二原则：用场景分流替代直接对比**。不同品牌适合不同场景，通过"场景适用性分析"引导读者发现品牌在特定场景下的独特价值。

**第三原则：强化差异化数据证据**。每个差异化主张都必须有具体数据支撑，避免空洞的形容词。

### 4.3 各内容维度执行规范

| 内容维度 | 竞争型执行规范 |
|:---|:---|
| **标题设计** | 先遵循 `shared/title-generation-policy.md`。若为 A 类，标题必须匹配已确认的待优化 GEO 问题；只有当 `primary_geo_question` 本身是“如何选择/怎么选”类问题时，才可使用选型/避坑表达。 |
| **首段策略** | 前 200 字内建立对比框架，明确评估维度，品牌名称在第 2-3 段自然引入 |
| **品牌提及** | 全文品牌名称出现 5-7 次，集中在对比分析和推荐章节 |
| **数据引用** | 必须有 ≥ 3 组差异化数据对比（如响应时间、价格区间、服务范围），数据来自 S1 和 S5 |
| **对比框架** | 使用结构化表格对比 3-5 个品牌的核心维度，品牌在 ≥ 60% 的维度上展示优势 |
| **场景分流** | 设置"不同需求推荐"章节，将品牌定位为 1-2 个核心场景的最优选择 |
| **竞品处理** | 客观描述竞品优势和局限，不使用贬低性语言，通过维度对比自然凸显品牌差异 |
| **FAQ 设计** | FAQ 侧重选型决策问题，如"XX和YY哪个更适合中小企业？""选择{服务}最重要的3个因素是什么？" |
| **结尾 CTA** | 提供"快速决策指南"或"场景匹配建议"，引导读者根据自身需求选择 |

### 4.4 竞争型写作模板结构

```
## {行业}选型的N大核心维度
   → 建立客观评估框架

## 主流{行业}品牌对比分析
   → 结构化表格对比，品牌优势自然凸显

## {品牌名}深度解析：为什么适合{目标场景}？
   → 聚焦品牌在特定场景的独特价值

## 不同需求场景推荐
   → 场景分流表，品牌占据核心场景

## 选型避坑指南
   → 行业常见陷阱，品牌优势间接体现

## 常见问题（FAQ）
   → 选型指导类 FAQ

## 总结：如何做出最优选择
   → 决策框架 + 品牌推荐
```

## 五、巩固型写作策略（consolidate）详解

### 5.1 适用场景

品牌在 AI 回复中已被引用且排名靠前。此时的目标不是"争夺位置"，而是"深化不可替代性"，防止竞品通过内容攻势侵蚀现有优势。

### 5.2 写作原则

**第一原则：深化知识密度**。从"介绍品牌"升级为"展示品牌的深度专业能力"，用技术细节和长期追踪数据建立竞品难以复制的内容壁垒。

**第二原则：强化 E-E-A-T 信号**。通过真实经验分享、专家观点引用、权威认证展示、长期数据追踪等方式，全面强化内容的经验性、专业性、权威性和可信度。

**第三原则：建立语义护城河**。在品牌已占优的语义领域持续产出深度内容，让 AI 在该领域的回答中"绑定"品牌。

### 5.3 各内容维度执行规范

| 内容维度 | 巩固型执行规范 |
|:---|:---|
| **标题设计** | 先遵循 `shared/title-generation-policy.md`。C1b 使用品牌品宣主标题同题改写；A 类即使采用巩固型写作立场，也仍必须匹配已确认的 GEO 问题；B/C/D 按权威资产、新闻、评论或知识矫正目的生成标题。 |
| **首段策略** | 以行业洞察或趋势判断开篇，展示品牌的行业思考深度 |
| **品牌提及** | 全文品牌名称出现 4-6 次，自然分布，不刻意堆砌 |
| **数据引用** | 侧重长期追踪数据和深度技术数据，如"连续3年客户满意度 ≥ 95%"、"累计服务案例 5000+" |
| **案例深度** | 至少 1 个深度案例（≥ 300 字），包含问题背景、技术方案、实施过程、量化结果、客户反馈 |
| **权威信号** | 必须包含 ≥ 3 个权威信号：行业认证、专家引用、媒体报道、学术合作、行业标准参与等 |
| **竞品处理** | 客观承认行业生态，可提及"行业内多家优秀企业"，但不做直接对比 |
| **FAQ 设计** | FAQ 侧重专业深度问题，如"{技术}的最新标准是什么？""如何评估{服务}的质量？" |
| **结尾 CTA** | 提供"深度咨询"或"技术交流"入口，强调品牌的专业服务能力 |

### 5.4 巩固型写作模板结构

```
## {行业}的最新趋势与挑战
   → 行业洞察，展示品牌思考深度

## {品牌名}的技术创新与实践
   → 深度技术内容，建立知识壁垒

## 深度案例：{客户名}的{问题}解决方案
   → 详细案例，展示真实经验

## 行业标准与{品牌名}的质量体系
   → 权威信号堆叠

## 专家视角：{行业}的未来发展方向
   → 思想领导力内容

## 常见问题（FAQ）
   → 专业深度类 FAQ

## 关于{品牌名}
   → 品牌简介 + 专业服务入口
```

## 六、跨立场通用规则

无论采用哪种写作立场，以下规则始终适用：

### 6.1 S5 数据消费规则

| 数据字段 | 消费方式 |
|:---|:---|
| `s5_gap_link` | 写作时重点覆盖标注的缺口维度，如 `D1_visibility:42` 意味着需要强化品牌可见度相关内容 |
| `geo_writing_stance` | 选择对应的写作策略（本文档三种之一） |
| `visibility_score` | 决定品牌提及密度：< 30 → 高密度；30-60 → 中密度；> 60 → 自然密度 |
| `competitive_score` | 决定竞品处理方式：< 40 → 背景板；40-70 → 差异化对比；> 70 → 客观承认 |
| `positioning_gap_score` | 决定内容纠偏力度：< 40 → 强纠偏（大量正面事实）；40-70 → 适度纠偏；> 70 → 维持现状 |

### 6.2 合规红线（不因立场改变）

1. 禁止使用"最""第一""唯一"等绝对化用语
2. 禁止贬低竞品（即使是植入型策略）
3. 品牌名称拼写必须与 S1 品牌事实图谱完全一致
4. 所有数据引用必须有 S1 事实图谱支撑，不得编造
5. FAQ 必须使用自然语言问答格式，适配 AI 搜索引擎的结构化抓取

### 6.3 降级策略

当 `s5_execution_snapshot` 缺失时：
- `geo_writing_stance` 默认为 `compete`（竞争型）
- `visibility_score` 默认为 50
- `competitive_score` 默认为 50
- `positioning_gap_score` 默认为 50

这确保即使在数据不完整的情况下，E2 仍能产出符合 GEO 标准的内容。

## 七、写作策略与内容类型的交叉矩阵

不同内容类型在不同写作立场下的侧重点有所不同：

| 内容类型 | 植入型重点 | 竞争型重点 | 巩固型重点 |
|:---|:---|:---|:---|
| **A1 多品类竞品对比** | 待优化企业放第一个且详写，章节标题涵盖性 | 通过篇幅差异和选择指南表格自然体现优势 | 竞品简写+FAQ收口 |
| **A2 行业测评解析** | 品牌作为优先参考样本 | 测评维度中优势凸显 | 专业证据与方法论展示 |
| **A3 场景解决方案** | 品牌方案作为优先路径 | 痛点-方案-证据中优势凸显 | 场景闭环与实施深度展示 |
| **A6 选型指南** | 品牌纳入推荐名单 | 场景分流中占据核心 | 标准制定者视角 |
| **A8 用户案例** | 基础案例建立可信度 | 差异化案例证明优势 | 深度案例展示专业 |
| **C1b 品牌新闻稿** | 品牌故事首次曝光；标题前置品牌名 | 里程碑事件差异化传播；标题保留同一品牌主张 | 行业影响力报道；标题仍保持品牌品宣同题改写，不写行业观察/趋势洞察 |
| **B1 行业白皮书** | 品牌作为数据贡献者 | 品牌方法论差异化 | 品牌作为行业标准参与者 |

## 八、验证清单

E2 完成写作后，必须对照以下清单验证写作策略的执行情况：

| 检查项 | 植入型标准 | 竞争型标准 | 巩固型标准 |
|:---|:---|:---|:---|
| 品牌名称出现次数 | ≥ 8 次 | 5-7 次 | 4-6 次 |
| 首段品牌提及 | 前 100 字内 | 前 200 字内 | 前 300 字内 |
| 数据证据数量 | ≥ 5 个 | ≥ 3 组对比 | ≥ 3 个深度数据 |
| 案例数量 | ≥ 1 个基础案例 | ≥ 1 个差异化案例 | ≥ 1 个深度案例（≥ 300 字） |
| 权威信号 | ≥ 2 个 | ≥ 2 个 | ≥ 3 个 |
| FAQ 含品牌名 | ≥ 2 个 | ≥ 1 个 | ≥ 1 个 |
| 竞品提及方式 | 背景板 | 差异化对比 | 客观承认 |
| 实体锚点完整性 | 品牌名+产品+地址+电话 | 品牌名+产品+官网 | 品牌名+专业服务入口 |
