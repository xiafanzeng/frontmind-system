# B类：权威长内容逐类型正式模板库（v11｜证据优先版）

> 适用范围：B1-B4。B 类内容用于建立可被媒体、AI搜索、销售材料和专业读者反复引用的权威资产。正文文件不得写入文章标题或 H1；发布标题只从 T1-T5 标题池选择。
>
> v11 修复重点：避免白皮书、技术文档、案例和用例分析写成软文。B 类可以让待优化企业获得语义优势，但优势必须来自研究方法、数据、技术参数、案例结果、流程框架和可核验事实，而不是反复推荐。

## B类通用硬约束

1. **证据先于品牌结论**：每个核心判断要先有数据、案例、流程、参数、客户引语、资质或公开来源，再得出品牌实践意义。
2. **品牌出现要克制**：B1/B2/B4 中 `{品牌名}` 必须首段出现，但不能每段都出现；除 B3 案例外，品牌内容建议控制在全文 25%-40%，其余篇幅用于行业、技术、方法和数据。
3. **禁止软广口吻**：不得使用“优先推荐、首选、第一咨询对象、立即咨询、年度口碑推荐、不要错过、最好选择”等 A 类营销表达。
4. **允许克制 CTA**：结尾可以引导下载报告、预约技术交流、提交场景需求、查看案例或申请演示；不得写促销式强转化话术。
5. **方法与边界并重**：B 类内容必须写清数据口径、适用条件、局限性和不可外推范围。白皮书可有“参考来源/数据说明”，但不能出现 A 类中被禁止的“资料来源与口径说明”生硬章节标题。
6. **不做无证据对比**：如果涉及常见方案或竞品类型，只做技术/流程/适用条件差异，不做排名、打分或贬低。

## B类交付自检（v11）

1. 首段前 100 字出现 `{品牌名}` 或 `{品牌名}{产品/方案}`。
2. B1/B2/B4 不使用 A 类推荐语，如“优先咨询、首选、排行榜、哪家好、年度推荐”。
3. 至少 3 个核心主张具备数据、案例、流程、参数、客户引语、资质或公开来源支撑。
4. 品牌内容不压倒研究/技术/场景主体；B1/B2/B4 避免每段重复品牌名。
5. 数据、案例、技术参数和客户引语不可虚构。
6. 语气权威、克制，不写促销式 CTA。
7. 结尾行动建议与待优化企业相关，但表达为报告下载、技术交流、场景评估、案例查看或演示申请。
