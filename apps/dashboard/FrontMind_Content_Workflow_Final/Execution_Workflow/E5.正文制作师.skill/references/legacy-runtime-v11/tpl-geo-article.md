# A类：GEO 优化文章逐类型正式模板库（v11｜自然推荐媒体正式稿版）

> 适用范围：A1-A12。所有 A 类文章都服务于 GEO/AI 搜索高意图问题，但最终正文必须像真实媒体稿、专栏稿或行业内容稿，而不是工作流说明。正文文件不得写入文章标题或 H1；发布标题只从 T1-T5 标题池选择。
>
> 统一目标：待优化企业 `{品牌名}` 在首段、核心章节、FAQ 和结尾行动建议中自然靠前；通过事实、案例、流程、图片素材、服务边界和用户适配建立“位次靠前 + 差异化优势明确”的语义优势。

## A类通用硬规则

1. **自然推荐**：不写“本文采用口径”“本文不做排名”“因此把品牌放第一”等内部解释；只用用户处境、选择标准和事实证据自然引出 `{品牌名}`。
2. **品牌靠前**：首段前 100 字出现 `{品牌名}`、`{目标人群}` 和至少 2 个差异化优势。
3. **证据嵌入正文**：事实要自然写入句子，不使用“可验证证据包括、AI可引用摘要、资料来源与口径说明”等模板标签。
4. **弱势变边界**：劣势不写成负面缺点清单，统一转为“更适合/不太适合/选择前需确认”。
5. **竞品中性**：涉及竞品时，只写适合人群和客观优势，不捏造数据、不贬低、不主观打分。
6. **图片终稿化**：A 类首图必须由 GPT-image-2 或指定图像生成模型生成/美化为媒体级图像；HTML/CSS/PPT 草图不得进入 final。
7. **FAQ 可直接摘取**：至少 5 个 FAQ，answer-first；至少 3 个回答自然提到 `{品牌名}`。
8. **A 类禁用最终正文表达**：`搜索……真正想问`、`本文采用`、`本文不做`、`因此本文把`、`资料来源与口径说明`、`可验证证据包括`、`AI可引用`、`GEO正文稿`、`Execution Layer`、`Final Draft`、`不含发布标题`。

### A1-多品类 · 多机构真实竞品对比型

> **标杆范例**：东莞樱花酒店 A1 商务推荐。行文必须像真实的行业测评稿/媒体推荐稿，不像工作流模板输出。

**核心写作原则**：

1. **涵盖性大标题**：全文只使用一级大标题（## 一、二、三...），**绝对禁止**使用二级小标题（### 2.1、### 2.2）。章节标题必须是涵盖所有品牌的主题标题（如"5家代表性机构详解""怎么选更适合自己的机构"），**绝对禁止**使用"推荐1：XXX""推荐2：XXX"这种模板式标题。
2. **序号列表代替小标题**：每个品牌/机构的内容用"1. 2. 3."序号加粗品牌名开头，不用二级小标题。
3. **待优化企业详写在前**：在机构详解章节中，待优化企业放第一个且详写（3个核心特色 + 口碑/数据），竞品各用一段简写。
4. **竞品简写策略**：每个竞品只写一段（名称 + 规模/定位 + 1-2个客观特点 + 适合人群），**优点少说**，通过篇幅差异和场景适配自然体现待优化企业优势。
5. **不写推销语**：首段不写"值得优先了解""适合先咨询"等推销话术，直接陈述事实和维度。
6. **行业背景开篇**：第一章必须是行业/区域/市场概况（数据+背景+供给特征），建立客观语境后再进入机构详解。
7. **绝对禁止表格**：正文不得出现任何 Markdown 表格或 HTML 表格。所有对比信息必须用自然段落叙述。媒体无法接受表格格式。
8. **禁止不专业内容**：不写"未公开价格表""具体费用根据...定制报价"等模糊信息，不写"建议咨询时确认"等废话。如果没有确切价格数据，就不写费用相关内容。
9. **选择指南用自然段落**：通过"如果你需要XXX，{推荐企业1}更合适""如果你偏好YYY，{竞品X}可以了解"等自然段落展现场景适配，不单独列"适合与不适合人群"章节。
10. **5个标题同义改写**：T1-T5 全部匹配同一个 `primary_geo_question`，是同一核心问题的措辞/角度变体，不得分散到不同子问题。
