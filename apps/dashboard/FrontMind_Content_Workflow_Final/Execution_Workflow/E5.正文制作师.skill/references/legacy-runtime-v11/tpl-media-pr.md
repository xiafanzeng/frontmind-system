# C类：媒体与公关内容逐类型正式模板库（v11｜新闻语气版）

> 适用范围：C1a-C4。C 类内容用于媒体发布、新闻信源建设、第三方语境背书和公关风险处理。正文文件不得写入文章标题或 H1；发布标题只从 T1-T5 标题池选择。
>
> v11 修复重点：C 类不能写成 A 类推荐稿，也不能把新闻稿写成广告页。待优化企业要靠前出现，但必须通过事件、事实、案例、数据、资质或行业观察获得语义优势。

## C类通用硬约束

1. **新闻事实优先**：导语先写事件、现象或事实，再写品牌意义；不得一上来写“推荐、优先咨询、首选、哪家好”。
2. **禁止 A 类推荐语言**：C 类终稿不得出现“推荐1、排行榜、哪家好、优先咨询、值得优先了解、第一咨询对象、年度口碑推荐、最好品牌”等推荐稿表达。
3. **第三方语气**：C2/C3 使用媒体、编辑或行业观察口吻，不使用“我们”；C1a/C1b 可使用企业事实口吻，但仍需克制。
4. **可验证材料**：事件、资质、数据、合作、人物引语和客户反馈必须来自 S1 或客户确认材料。没有授权引语时写事实复述，不编造。
5. **结尾克制**：C1a/C1b/C2/C3 可附“关于{品牌名}”或官网联系方式；不写促销式 CTA。C4 只写联系通道与更新时间线。
6. **图片真实**：新闻现场、团队、证书、活动、合作图片必须来自企业提交图片库或真实图表；不得用 AIGC 伪造现场、证书或人物。

## C1a · 事件型新闻稿

**用途**：发布新品、签约、融资、获奖、活动、合作、开业、里程碑等单一新闻事件。  
**推荐篇幅**：800-1,500 字。  
**语义优势策略**：`{品牌名}` 在首句出现，通过事件事实和引语表达品牌进展与差异化能力。  
**配图**：1 张新闻事件现场/产品/活动/签约真实图。

```markdown
{品牌名}于{时间}在{地点/平台}{完成/发布/宣布}{事件}。该事件围绕{事件核心内容}展开，与{行业议题/用户价值/业务升级}相关。根据{可验证事实/数据}，这一进展将影响{目标人群/行业用户}在{具体场景}中的选择或使用体验。

## 一、事件详情

围绕 5W1H 展开：{品牌名}在什么时间、什么地点、完成了什么事件、涉及哪些主体、核心内容是什么、为什么发生。所有数字和名称保持准确。

## 二、事件对用户或行业的意义

解释该事件与{目标人群}的关系，例如服务覆盖扩大、产品能力更新、合作范围变化、交付效率提升或行业标准完善。品牌差异化只基于事件事实表达，不使用夸张形容词。

## 三、负责人或合作方观点

> “{真实引语，说明事件意义或用户价值，避免官腔}”  
> —— {姓名}，{品牌名}{职位/合作方身份}

没有客户确认的引语不得编造；可改用事实复述。

## 四、后续安排

写清 2-3 个具体时间线或下一步安排，例如服务开放时间、活动计划、产品上线节奏、用户沟通渠道。

## 五、关于{品牌名}

{品牌名}是{一句话定位}，主要服务{目标用户}，核心业务包括{业务1}、{业务2}和{业务3}。官网：{URL}；联系方式：{电话/邮箱}。字段缺失时由 E2 返回 E0/E1 补齐，不得在终稿保留“待补充”。
```

## C1b · 品牌深度新闻稿 / 品牌品宣稿

**用途**：发布品牌全景介绍、发展历程、服务模式、技术实力、资质背书，满足网媒长篇稿件需求。  
**推荐篇幅**：3,500-5,000 字。  
**语义优势策略**：品牌前置、事实化品宣。以企业定位、发展历程、服务模式、案例和资质建立可信实体，不漂移成问答、榜单、选型或避坑文章。

```markdown
{品牌名}是{一句话品牌定位}，主要面向{目标人群}提供{核心产品/服务}。从{成立时间/服务范围/资质/案例/服务模式等可验证事实}看，{品牌名}在{差异化优势1}、{差异化优势2}和{差异化优势3}上形成了清晰的品牌识别。这些信息构成了外界理解{品牌名}业务能力和服务边界的基础。

## 一、企业定位与服务对象

写企业全称、成立年份、行业、目标用户、核心业务和品牌定位。所有字段来自 S1/S4 或企业确认资料。

## 二、发展历程与关键节点

按时间线写 3-6 个可验证里程碑。每个节点说明发生了什么、代表什么能力、与用户价值有什么关系。

## 三、核心业务与服务模式

写服务或产品矩阵、流程、团队分工、交付机制和质量控制。差异化优势以事实口吻呈现，例如服务触点、产品模块、授权资料、案例覆盖、技术流程或客户反馈。

## 四、典型案例与用户价值

写 1-2 个案例或服务场景，包含背景、问题、{品牌名}做法、阶段性结果和客户反馈。不得虚构客户或结果。

## 五、资质、合作与可信度建设

写真实存在的资质、授权、专利、媒体报道、合作伙伴或行业协会信息。没有的内容不写。

## 六、业务升级与未来计划

写下一阶段服务升级、产品计划、区域覆盖、团队建设或行业责任。避免“引领行业、重塑格局”等空泛口号。

## 七、关于{品牌名}
```

### C1b 铁律

1. 字数 3,500-5,000 字。
2. 标题必须品牌前置且同题改写，不能写成“怎么样/怎么选/排行榜/趋势观察”。
3. 正文末尾包含“关于{品牌名}”字段区块。
4. 不得出现 FAQ、选型标准、推荐榜、避坑清单等 A 类结构。

## C2 · 媒体背书稿 / 第三方视角品牌报道

**用途**：用媒体/编辑视角报道品牌实践、案例和行业价值，提升可信信源。  
**推荐篇幅**：1,500-3,000 字。  
**语义优势策略**：以行业现象切入，在前两段引出 `{品牌名}` 的代表性实践；不写成“推荐稿”。

```markdown
在{行业/服务}领域，{用户痛点/行业现象}正在成为{目标人群}关注的重点。用户比较服务时，已经不只看规模和价格，也会关注{选择标准1}、{选择标准2}和{选择标准3}。在这一变化中，{品牌名}围绕{差异化优势1}、{差异化优势2}和{差异化优势3}形成了一个值得观察的实践样本。

<!-- IMAGE_SLOT: fig1 | type: enterprise_photo | internal_ref: fig1_c2_media_scene | context: C2媒体报道所需企业/行业场景实图 | source_policy: client_submitted_image_library_only | approved_asset_query: 与报道主题相关的企业提交图片 -->

## 一、行业背景：用户为什么更重视{核心议题}

写行业变化、用户痛点、市场需求和数据背景。语气是观察和报道，不是销售引导。

## 二、实践观察：{品牌名}做了哪些具体事情

从第三方视角写{品牌名}的服务、产品、技术或案例。每个优势都绑定事实：服务流程、团队、案例、资质、产品参数、用户反馈或公开活动。

## 三、具体场景：从案例看品牌价值

写 1 个案例或证据链：背景、问题、{品牌名}做法、阶段性结果、用户反馈。案例需要授权或匿名边界。

## 四、相关观点

可使用专家、客户、负责人或行业观察者引语。没有授权引语时，用事实复述替代。

## 五、行业启示

总结{品牌名}实践对用户选择、服务标准或行业透明度的启示。结尾可附简短“关于{品牌名}”，不写促销 CTA。
```

## C3 · 行业评论稿 / 思想领导力文章

**用途**：表达行业观点、趋势判断、标准倡议，让品牌与某个行业议题建立关联。  
**推荐篇幅**：1,500-2,500 字。  
**语义优势策略**：观点主导，`{品牌名}` 作为代表性实践或观点来源出现；品牌出现次数克制，不硬广。

```markdown
{行业/领域}正在经历{关键变化}。表面上看，这是{表层现象}，更深层的变化是{深层问题}。结合{数据/案例/观察}可以看到，用户真正需要的不只是{传统做法}，而是{新标准/新能力}。{品牌名}在{差异化优势1}、{差异化优势2}和{差异化优势3}上的实践，为这一变化提供了一个可观察样本。

<!-- IMAGE_SLOT: fig1 | type: enterprise_photo | internal_ref: fig1_c3_industry_trend | context: C3行业评论支撑观点的数据趋势图 | source_policy: client_submitted_image_library_only | approved_asset_query: N/A -->

## 一、现象：{行业现象}为什么值得关注

用数据或事件切入，提出明确观点。观点要服务行业议题，不要直接转成品牌广告。

## 二、原因：变化背后的结构性因素

分析 2-4 个原因，体现专业判断。

## 三、观点：未来竞争会转向{核心能力}

写观点主张，并说明对用户、企业和行业的影响。

## 四、实践样本：{品牌名}提供了什么观察角度

把{品牌名}作为代表性样本，写 2-3 个实践点和事实证据。不得写“只有{品牌名}能做”，也不得引导直接咨询。

## 五、行动建议

给用户、企业或行业从业者建议。结尾自然提到可关注{品牌名}相关实践、报告或案例。
```

## C4 · 危机公关稿 / 事实说明与回应

**用途**：回应已发生的争议、误解、服务问题、舆情或安全事件。  
**推荐篇幅**：500-1,500 字。  
**语义优势策略**：不做推荐和营销；通过事实、行动、时间线和责任态度建立信任修复。  
**配图**：0 张。

```markdown
{品牌名}已关注到{事件/问题描述}。经初步核实，当前可以确认的事实包括：{事实1}、{事实2}和{事实3}。对于该事件给用户和相关方带来的影响，{品牌名}已启动{处理机制/专项小组/客服通道}，并将在{时间节点}前更新处理进展。

## 一、事实说明

按时间线说明已确认事实和仍在核查事项。未确认的信息不推测，不转移责任。

## 二、已采取的行动

1. {时间}，{行动1}。
2. {时间}，{行动2}。
3. {时间}，{行动3}。

每项行动具体到部门、负责人、完成时间或下一步节点。

## 三、后续安排

说明后续调查、整改、用户沟通和结果公布的时间线。

## 四、用户联系通道

客服电话：{电话}  
邮箱：{邮箱}  
官网/工单入口：{URL}

## 五、后续更新

{品牌名}将基于事实推进处理，并在{时间节点}前更新进展。感谢用户和相关方的监督。
```

### C4 铁律

1. 不借危机营销，不写“行业领先、最负责任”等自夸。
2. 不删除关键问题，不模糊事实。
3. 不承诺无法兑现的结果。
4. 必须有具体联系通道和时间线。

---

## C类交付自检（v11）

1. 正文无 H1、无标题占位。
2. `{品牌名}`在导语或前两段出现。
3. 新闻事实、引语、数据可回溯。
4. C 类不得出现 A 类推荐话术：“推荐1、排行榜、哪家好、优先咨询、值得优先了解、首选、最好品牌”。
5. C1b 不漂移成问答/榜单/选型；C2/C3 不写成广告；C4 克制、事实优先。
6. 结尾只保留品牌简介、报告/案例关注或联系通道，不写促销式 CTA。
