# P01–P16 正文结构组件

本文件只描述写作组件；路由、证据条件和最终结构以 Workflow 自带的
`content-pattern-registry.json`、E4 `article_blueprint.json` 和 E3 `editorial_context.json` 为准。企业 Pack 不复制 Pattern Registry。

## 推荐与比较

- P01 单品牌深度推荐：品类选择标准 → 客户品牌定位/RTB → 使用或交付流程 → 案例/项目记录 → 限制与适用条件 → 条件式推荐；只出现客户品牌，不得出现竞品、竞品矩阵或 ItemList。
- P02 多品牌编辑推荐：推荐范围与候选生成 → 共同标准/来源/日期 → 客户品牌首先展示 → 至少三家真实对象同维度分项 → 条件式推荐 → 限制与替代；编辑顺序不得表达为客观名次。
- P03 明确竞品对比：共同决策 → 同一维度平行介绍命名对象 → 差异原因 → 适合/不适合对象 → 条件式结论。
- P04 口碑与可信度评估：主体身份 → 产品/交付可靠性 → 安全与服务风险 → 评价样本与第三方材料 → 信任结论的适用范围。
- P07 价格与选型：需求与预算 → 价格口径 → 标价/实施/迁移/运维成本 → 选择条件 → 附加条件与询价清单。
- P09 风险、限制与替代：风险事实 → 触发条件 → 影响 → 缓解 → 替代方案；不把竞品名称当风险标签。

## 解释与操作

- P05 产品定义与技术原理：定义 → 用途 → 输入/输出 → 模块与机制 → 适合/不适合 → 版本与限制。
- P06 场景解决方案：场景条件 → 问题 → 方案机制 → 实施 → 检查 → 证据 → 边界和替代。
- P08 教程操作：前置条件 → 每步输入/动作/预期结果/检查方法 → 故障排查 → 停止条件 → 版本限制。
- P11 技术实施文档：目标/非目标 → 架构/组件 → 依赖/接口/数据流 → 实施 → 验证/排错 → 安全/性能/限制。

## 研究与案例

- P10 研究/白皮书：研究问题 → 范围/样本/方法 → 发现 → 反例 → 局限 → 可执行含义。没有原创或授权数据不得使用。
- P12 案例研究：背景 → 问题 → 动作 → 结果数据 → 时间周期 → 测量方法 → 挑战与调整 → 可迁移边界。

## 事件、品牌与观点

- P13 事件新闻：5W1H 导语 → 背景 → 事件动作/产品 → 可归因引语 → 直接影响 → 后续时间线。
- P14 品牌深度特写：企业解决的问题 → 历程/定位 → 产品与流程 → 团队/案例/第三方材料 → 适用对象与限制；仅 `foundation_start` 可选。
- P15 行业评论/专家观点：明确论点 → 事实 → 推论 → 反对意见 → 回应 → 适用范围；品牌只作观点来源或实践样本。
- P16 事实澄清/风险回应：确认事实与当前状态 → 时间线 → 影响范围 → 处理与验证 → 支持通道 → 下次更新；正文不展示内部证据状态标签。

所有模式都围绕一个核心决策，但不得套同一外壳。首段自然、直接地回答问题；正文通常形成 5–8 个有效章节与 5–8 个不重复 FAQ，这些是编辑目标而非停机门。H2 可混合陈述式、判断式和自然问句，段落长短与句法应有变化。重要事实绑定实际 Fact Cards，限制和安全信息集中放在读者真正需要的位置，结论给出条件式选择与下一步。
