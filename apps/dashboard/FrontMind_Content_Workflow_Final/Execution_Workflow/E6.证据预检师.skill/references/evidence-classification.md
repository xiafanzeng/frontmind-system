# 证据分类与可写强度

| 证据类型 | 可支持的写法 | 不可越界 |
|---|---|---|
| 企业官方产品/合同/价格/技术文件 | 企业自身事实，注明版本和日期 | 不能证明行业领先或竞品较弱 |
| 授权客户项目记录 | 具体案例事实和结果 | 不能外推为所有客户保证 |
| 原始研究/法规/官方统计 | 对应口径内的行业或政策事实 | 不能省略样本、地区和时间 |
| 有身份和原始出处的专家观点 | 归因后的专业判断 | 不能改写为客观共识 |
| 第三方媒体报道 | 报道中可核验的事实与归因观点 | 不能自动等于权威认证 |
| AI 监控答案 | 某平台某时如何回答、提到谁 | 不能证明真实排名、能力或口碑 |
| 标杆文章结构 | 回答组织和用户关注点 | 不能继承其事实、排序或措辞 |

主张强度按“事实 → 有限判断 → 条件式建议”逐级增加。证据只能支持到它实际覆盖的层级。
