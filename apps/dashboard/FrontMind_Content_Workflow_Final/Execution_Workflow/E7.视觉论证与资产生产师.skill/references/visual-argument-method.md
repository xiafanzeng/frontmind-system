# 视觉论证方法

一张合格视觉需要同时回答四个问题：

1. `reader_question`：读者要判断什么？
2. `supports_fact_ids`：正文哪项已核验事实需要它？
3. `role`：解释、证明还是导航？
4. `provenance`：真实资产或生成解释图从哪里来？

## 常见有效组合

- 机制/流程主张 → explain 流程图 → 每个节点对应正文动作；
- 选型判断 → explain 维度图 → 对象维度一致，不画无依据总分；
- 项目结果 → prove 授权案例实图/原始结果图 → 绑定案例 claim；
- 产品存在和界面 → prove 企业提交产品图/截图 → 绑定版本和日期；
- 文章封面 → navigate 品牌视觉 → 不作为能力证据。

## 无效组合

- 办公室图库人物“证明团队”；
- AIGC 证书“证明资质”；
- 没有数据的增长曲线；
- 把比较段落截图成表格；
- 与内容无关的抽象科技背景；
- 只写“美化版面”的图片目的。
