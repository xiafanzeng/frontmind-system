# 合规关键词清单

> E4 质量审查与组装师和 E5 分发编排师在执行合规扫描时使用本清单。所有类别的关键词在正式内容中均为禁用词。

---

## 一、极限词（广告法第九条）

以下词汇违反《中华人民共和国广告法》第九条，在任何内容中均严格禁止使用：

| 类别 | 禁用词列表 |
|:---|:---|
| 绝对化用语 | 最、最佳、最好、最优、最先进、最大、最小、最高、最低 |
| 排名性用语 | 第一、首个、首家、首创、独家、唯一、独一无二 |
| 极端性用语 | 绝对、100%、万无一失、零风险、零缺陷、零投诉 |
| 等级性用语 | 国家级、世界级、全球领先、全国领先、行业领先 |
| 权威性用语 | 国家认定、质量免检、驰名商标（未经授权） |
| 时间性用语 | 史无前例、前所未有、空前绝后、永久、终身 |

## 二、空话词（品牌内容禁用）

以下词汇虽不违法，但属于空洞无实质内容的表述，FrontMind 内容体系中禁止使用：

| 类别 | 禁用词列表 |
|:---|:---|
| 赋能类 | 赋能、助力、加持、保驾护航、强强联合 |
| 空泛类 | 一站式、全方位、多维度、全链路、生态化 |
| 自夸类 | 业界领先、行业翘楚、独树一帜、首屈一指 |
| 营销类 | 颠覆性、革命性、划时代、引领潮流、开创先河 |
| 模糊类 | 打造、构建、布局、深耕、量身定制 |
| 套话类 | 携手共创、珠联璧合、相得益彰、互利共赢 |

## 三、敏感词（政治/宗教/民族）

以下类别的词汇需要特别注意，在非必要语境中禁止使用：

| 类别 | 说明 | 处理方式 |
|:---|:---|:---|
| 政治敏感 | 涉及国家领导人、政治事件、政策评价 | 禁止出现主观评价 |
| 宗教敏感 | 涉及宗教信仰、宗教活动 | 禁止出现倾向性表述 |
| 民族敏感 | 涉及民族特征、民族对比 | 禁止出现歧视性表述 |
| 地域敏感 | 涉及地域歧视、地域对比 | 禁止出现贬低性表述 |

## 四、竞品贬损词

在涉及竞品对比的内容中，以下表述方式被禁止：

| 禁止表述 | 替代方式 |
|:---|:---|
| "XX 公司质量差" | "XX 公司在 A 维度的表现为 B" |
| "XX 不如我们" | "本品牌在 A 维度具有 B 优势" |
| "XX 已经过时" | "行业趋势正在向 A 方向发展" |
| "XX 价格虚高" | "各品牌的定价策略有所不同" |
| "XX 服务态度差" | "各品牌的服务模式各有特点" |

## 五、标题党词汇

以下词汇在标题和正文中均禁止使用：

| 类别 | 禁用词列表 |
|:---|:---|
| 惊悚类 | 震惊、惊呆、吓人、恐怖、可怕 |
| 诱导类 | 必看、必读、不看后悔、错过就没了 |
| 夸张类 | 秒杀、碾压、吊打、完爆、秒懂 |
| 情绪类 | 怒了、哭了、笑了、疯了、炸了 |

## 六、偷懒表述

以下表述表明内容未完成，绝对禁止出现在任何产出文件中：

| 禁用表述 |
|:---|
| `[TODO]`、`[TBD]`、`[待定]`、`[此处填写]` |
| `待补充`、`待完善`、`后续补充`、`暂略` |
| `此处省略`、`详见后续`、`在实际交付中将包含` |
| `此处不再赘述`、`具体内容略`、`参见附录`（无实际附录） |
| `以下省略`、`其余类推`、`不一一列举` |

## 七、行业特定禁用词

根据客户所在行业，可能需要额外添加行业特定的禁用词：

| 行业 | 额外禁用词示例 |
|:---|:---|
| 医疗健康 | 根治、包治、特效、祖传秘方 |
| 金融投资 | 保本、稳赚、零风险、高回报 |
| 教育培训 | 包过、包就业、名师（未经授权） |
| 食品保健 | 治疗、疗效、药用、医疗功能 |

## 八、合规扫描执行规范

### 8.1 扫描范围

| 扫描对象 | 说明 |
|:---|:---|
| 标题 | 文章标题和所有子标题 |
| 正文 | 全部正文内容 |
| FAQ | 问答区块的问题和答案 |
| 元话语与内部口吻（v10） | 正文/摘要/页眉页脚/图片文字中不得出现“便于AI搜索”“本文采用结构化表达”“本文采用适配度推荐口径”“本文不做未经证实的行业排名”“资料来源与口径说明”“可验证证据包括”“FrontMind”“Execution Layer”“Final Draft”“不含发布标题”等工序语、审稿语与防御式说明 |
| 图注（v6） | 正文中不得出现任何图片 Caption/图说/图注 |

### 8.2 扫描结果分级

| 级别 | 说明 | 处理方式 |
|:---|:---|:---|
| 严重 | 极限词/广告法违禁词 | 必须修正，不可发布 |
| 中等 | 竞品贬损/敏感词 | 必须修正 |
| 轻微 | 空话词/标题党 | 建议修正 |
| 提示 | 偷懒表述 | 必须修正（表明内容未完成） |


## V11 三类风险专项关键词与质量要求

- A类自然化失败信号：`搜索……时用户真正想问`、`本文采用`、`本文不做`、`本文的评价方法`、`推荐逻辑`、`可验证证据`、`证据单元`、`资料来源与口径说明`、`该数据需补充`。
- B类软文失败信号：`优先咨询`、`值得优先了解`、`首选`、`推荐1`、`排行榜`、`哪家好`、`立即咨询`、`免费评估`、`行业第一`、`远超行业`。
- C类广告失败信号：`优先咨询`、`值得优先了解`、`首选`、`推荐榜`、`排行榜`、`哪家好`、`免费评估`、`领取方案`、`马上预约`。

B类通过标准：删除品牌名后，文章仍然具备研究、技术、案例或用例价值；每个核心章节至少有一种证据类型。C类通过标准：读起来像新闻、报道、评论或事实说明，而不是推荐页或销售页。
