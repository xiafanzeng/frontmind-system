# 四维审查评分细则

> E4 质量审查与组装师在执行质量审查时必须遵循本评分细则。每一维度均有明确的评分标准和通过阈值。

---

## 一、评分体系概述

### 1.1 四维审查框架

| 维度 | 权重 | 通过阈值 | 审查对象 |
|:---|:---|:---|:---|
| 文字审查 | 40% | ≥ 80 分 | E2 文字稿件 |
| 图片审查 | 25% | ≥ 85 分 | E3 视觉资产 |
| 图文匹配审查 | 20% | ≥ 80 分 | 文字 + 图片整体 |
| 合规审查 | 15% | = 100 分 | 全文 |

**总体通过条件**：四维审查每一维度均达到通过阈值，且加权总分 ≥ 85 分。

### 1.2 评分等级

| 等级 | 分数范围 | 说明 |
|:---|:---|:---|
| A（优秀） | 90-100 | 可直接发布 |
| B（良好） | 80-89 | 需要小幅修正 |
| C（需改进） | 60-79 | 需要较大修正 |
| D（不合格） | < 60 | 需要退回重做 |

---

## 二、文字审查评分细则（40%）

### 2.1 字数达标（15 分）

| 达标率 | 得分 |
|:---|:---|
| ≥ 100% | 15 分 |
| 95%-99% | 12 分 |
| 90%-94% | 8 分 |
| 80%-89% | 4 分 |
| < 80% | 0 分（一票否决） |

### 2.2 S6 话语 Token 命中率（15 分）

| 命中率 | 得分 |
|:---|:---|
| ≥ 85% | 15 分 |
| 70%-84% | 12 分 |
| 60%-69% | 8 分 |
| 50%-59% | 4 分 |
| < 50% | 0 分（一票否决） |

### 2.3 结构完整性（10 分）

| 检查项 | 分值 | 标准 |
|:---|:---|:---|
| 结论先行 | 3 分 | 首段 100 字内含结论性回答 |
| 章节完整 | 3 分 | 所有章节有实质内容，无空壳 |
| FAQ 区块 | 4 分 | A 类文章含 5-8 个 Q&A |

### 2.4 内容质量（10 分）

| 检查项 | 分值 | 标准 |
|:---|:---|:---|
| 事实准确性 | 4 分 | 与 S1 品牌事实图谱一致 |
| 逻辑连贯性 | 3 分 | 段落间逻辑通顺 |
| 重复率 | 3 分 | < 3% |

### 2.5 文字审查一票否决项

以下任一项不达标，文字审查直接判定为不合格（D 级）：
- 字数达标率 < 80%
- S6 Token 命中率 < 50%
- 发现偷懒表述（`[TODO]`、`待补充`、`此处省略`）
- 重复率 ≥ 10%

---

## 三、图片审查评分细则（25%）

### 3.1 技术质量（15 分）

| 检查项 | 分值 | 标准 |
|:---|:---|:---|
| 文件大小 | 5 分 | 每张 ≥ 10KB |
| 分辨率 | 5 分 | AIGC ≥ 1024px / 数据图 ≥ 800px |
| 格式正确 | 5 分 | PNG/WebP/SVG |

### 3.2 S7 规范契合度（10 分）

| 检查项 | 分值 | 标准 |
|:---|:---|:---|
| S7 Prompt 引用 | 5 分 | AIGC 图有 s7_prompt_ref 记录 |
| 风格一致性 | 3 分 | 同篇 AIGC 图风格统一 |
| 文字控制 | 2 分 | `no_text` 图片无可见文字 |

### 3.3 图片审查一票否决项

- 任何图片文件大小 < 5KB
- AIGC 图片无 S7 Prompt 引用记录
- 数据图表缺少数据来源标注

---

## 四、图文匹配审查评分细则（20%）

### 4.1 语义匹配（12 分）

| 检查项 | 分值 | 标准 |
|:---|:---|:---|
| 图片语境匹配 | 6 分 | 图片内容与上下文语义匹配（禁止添加 Caption） |
| 图片位置合理 | 6 分 | 图片插入位置与讨论内容对应 |

### 4.2 完整性（8 分）

| 检查项 | 分值 | 标准 |
|:---|:---|:---|
| IMAGE_SLOT 全部替换 | 4 分 | 无残留 IMAGE_SLOT |
| 图片数量匹配 | 4 分 | 实际图片数 = image_requirements 中的数量 |

---

## 五、合规审查评分细则（15%）

**合规审查采用扣分制，满分 100 分。**

### 5.1 扣分标准

| 违规类型 | 每次扣分 | 说明 |
|:---|:---|:---|
| 极限词 | -20 分 | "最""第一""唯一"等 |
| 广告法违禁词 | -20 分 | "国家级""世界级"等 |
| 竞品贬损 | -15 分 | 对竞品的不当贬低 |
| 敏感词 | -10 分 | 政治/宗教/民族敏感 |
| 未标注引用 | -5 分 | 数据/引用缺少来源 |
| 空话词 | -3 分 | "赋能""一站式"等 |

### 5.2 合规审查通过条件

合规审查必须得到 100 分（零扣分）才能通过。任何扣分项都必须修正后重新审查。

---

## 六、审查报告输出格式

审查报告必须包含以下章节：

| 章节 | 内容 |
|:---|:---|
| 总体评价 | 四维得分 + 加权总分 + 等级 |
| 文字审查详情 | 字数/Token 命中率/结构/质量 |
| 图片审查详情 | 技术质量/S7 契合度 |
| 图文匹配详情 | 语义匹配/完整性 |
| 合规审查详情 | 扫描结果/违规列表 |
| 修正建议 | 具体的修正指导 |
| DOCX 组装参数 | WebP quality/文件大小 |


## V11 三类风险专项关键词与质量要求

- A类自然化失败信号：`搜索……时用户真正想问`、`本文采用`、`本文不做`、`本文的评价方法`、`推荐逻辑`、`可验证证据`、`证据单元`、`资料来源与口径说明`、`该数据需补充`。
- B类软文失败信号：`优先咨询`、`值得优先了解`、`首选`、`推荐1`、`排行榜`、`哪家好`、`立即咨询`、`免费评估`、`行业第一`、`远超行业`。
- C类广告失败信号：`优先咨询`、`值得优先了解`、`首选`、`推荐榜`、`排行榜`、`哪家好`、`免费评估`、`领取方案`、`马上预约`。

B类通过标准：删除品牌名后，文章仍然具备研究、技术、案例或用例价值；每个核心章节至少有一种证据类型。C类通过标准：读起来像新闻、报道、评论或事实说明，而不是推荐页或销售页。

---

## V11 A/B/C 三类风险扣分项

- A 类出现内部口径、模板标签、资料来源与口径说明、搜索意图解释：重大失败，退回重写。
- B 类权威内容缺少研究/技术/案例/用例证据，或写成品牌软文：重大失败，退回重写。
- C 类媒体稿使用推荐榜、优先咨询、立即咨询等广告语言：重大失败，退回重写。
