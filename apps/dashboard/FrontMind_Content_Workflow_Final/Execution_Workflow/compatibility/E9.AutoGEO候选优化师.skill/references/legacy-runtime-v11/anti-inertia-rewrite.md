# 平台发布适配指南 (Platform Publishing Adaptation Guide)

本文档定义了 E5 HarnessGEO 优化正本的写作规范。核心原则：**每篇核心素材只有 1 个不带文章标题的正文正本，各平台发布时仅从 E4 审核后的 5 标题池中选标题；标题池必须在交付消息中可见。标题选择必须保持该篇文章的 `title_generation_policy`、`title_objective` 与 `title_anchor`：A 类不得偏离待优化 GEO 问题，C1b 不得偏离品牌品宣同题改写，B/C/D 不得偏离各自的资产、新闻、观点、澄清、知识或信息矫正目的。**

## 核心原则

> **FrontMind 分发哲学**：质量优先于数量。1 篇高质量正本在多个高权重渠道分发，远胜于 N 篇低质量改写版本分散投放。AI 搜索引擎更看重"内容的知识密度和信源权威性"，而非"同一内容的多个变体"。

## 各平台发布微调建议

E5 在生成《轻量适配指南》时，应为操作者提供以下维度的微调建议（由人工在实际发布时执行）：

### 维度一：标题适配

| 平台 | 标题选择方式 | 字数建议 | 约束 |
| :--- | :--- | :--- | :--- |
| 知乎 | A 类可选问题式标题；非 A 类只有在标题池已有社区友好表达时才选择 | 15-30字 | 不得把非问答目的文章强行问答化 |
| 小红书 | 仅在标题池已有用户场景表达时选择；否则沿用最稳健的标题 | 10-20字 | 不得临时新增“避坑/指南/排名”类标题 |
| 百家号/头条号 | 选择适合资讯流但仍保留 `title_anchor` 的标题 | 15-25字 | A 类保留 GEO 问题；C1b 保留品牌品宣；B/C/D 保留内容目的 |
| 微信公众号 | 可选更完整、解释性更强的标题 | 15-30字 | 不得把资产/澄清/知识文章改成泛洞察 |
| 掘金/CSDN | 技术/方法类文章可选实现或方法论标题 | 15-30字 | 仅适用于标题池和正文确有技术/方法论支撑的文章 |

### 维度二：摘要/导语裁剪

| 平台 | 摘要长度 | 裁剪策略 |
| :--- | :--- | :--- |
| 百家号/头条号 | 50-80字 | 提取正本核心结论，加入行业数据钩子 |
| 知乎 | 80-150字 | 提取核心论点，以问题形式引导阅读 |
| 小红书 | 30-50字 | 提取用户痛点，配合 emoji 增强可读性 |
| 微信公众号 | 100-200字 | 提取深度洞察，体现专业性 |

### 维度三：格式适配

| 平台 | 格式要求 | 注意事项 |
| :--- | :--- | :--- |
| 百家号/头条号 | 短段落（每段 ≤150字）、多小标题 | 移动端阅读优化 |
| 知乎 | 支持 Markdown、可用引用块和代码块 | 保留正本结构即可 |
| 小红书 | 短句、emoji 分隔、核心 Tips 加粗 | 正文 ≤1000字，超出则裁剪为精华版 |
| 微信公众号 | 长文可接受、注重排版美感 | 正本可直接使用，微调排版 |
| 掘金/CSDN | 技术文档风格、代码块高亮 | 保留正本结构即可 |

### 维度四：配图使用

| 平台 | 配图策略 |
| :--- | :--- |
| 所有平台 | 使用 E3/E4 产出的同一组配图，不需要为不同平台重新生成 |
| 百家号/头条号 | 确保首图为 3:2 比例，利于搜索出图 |
| 小红书 | 首图可裁剪为 3:4 竖版（如有需要） |

## 自检清单

生成《轻量适配指南》后，必须逐项确认：

- [ ] 是否为每个目标渠道从 E4 审核通过的 T1-T5 标题池中选择了 1 个标题？
- [ ] 标题是否保持本篇 `title_generation_policy`、`title_objective` 与 `title_anchor`，没有为了平台风格强行换题？
- [ ] A 类是否仍匹配已确认的 `primary_geo_question`？C1b 是否仍是品牌品宣同题改写？B/C/D 是否仍服务原定内容目的？
- [ ] 是否为每个目标渠道提供了摘要裁剪建议？
- [ ] 是否标注了需要格式微调的具体位置？
- [ ] 是否明确说明了"正本不做全文改写，仅做发布时微调"的原则？
- [ ] 是否为小红书等短内容平台提供了精华版裁剪方案（≤1000字）？
