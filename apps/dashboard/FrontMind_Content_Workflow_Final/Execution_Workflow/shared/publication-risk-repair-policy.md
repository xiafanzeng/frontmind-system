# 编辑风险自动修复政策 v2.3

E6 负责对事实和主张直接执行 `keep | qualify | rewrite | remove`，E8 负责在当前阶段内修订正文并输出安全编辑正本，E9/E10 在候选出现事实或语义漂移时整篇沿用 E8。修复结果记录为简短 warnings/修订摘要，不是下游准入回执。

| 风险 | 默认自动修复 |
|---|---|
| 没有直接回答主问题 | 重写首段直接答案，删除无关主题，让每节完成一个必要子问题 |
| 主张超过现有内容支持 | 限缩措辞、改写为可证实的局部事实，或删除该主张；不要求用户补审批账本 |
| 统计/价格缺口径 | 能确认时补日期、样本、单位、地区、版本和适用条件；无法确认时删除数字或改为不含数值的诚实表述 |
| 竞品比较不公平 | 使用同一组最低维度、相同时间口径和平行顺序；未知信息保持未知，不用客户材料推断竞品缺点 |
| 像模板或出现工作流元话语 | 删除“这一部分需要回答”、事实条数、内部状态和重复句式，用问题特有的事实、条件和建议重写 |
| 用户确认的 P 与问题或硬条件不匹配 | E4 返回同一个 `awaiting_pattern_confirmation`，展示可行备选与具体缺口；不得静默改 P，也不建立独立决策文件 |
| 品牌宣传过强 | 用实际服务、流程、产品、参数、案例、限制和适用条件替换空泛形容词 |
| 医疗、隐私或保密内容越界 | 排除个人信息、内部/保密内容和高风险操作细节；医疗信息限定为一般决策信息，明确需要合资质专业人员面诊评估 |
| 视觉不可用 | 丢弃该图并继续纯文字成稿；只检查实际使用的图片 |
| HarnessGEO 改变事实、限制或 FAQ 语义 | 丢弃整篇候选，沿用 E8 编辑正本，不做段落级混拼 |

只有核心问题在删除、限缩和诚实改写后仍必须编造数字、事件、排名、竞品结论或疗效才能回答时，才可阻断整篇文章。某条事实不足、缺第三方材料、缺图片或单页访问失败，只能触发限缩、删除、模板兜底或纯文字交付；P02 候选数量等模式硬条件无法成立时回到既有 P 确认点。HarnessGEO 是部署环境中的正式 E9 调用；调用异常必须明确报告为部署错误，不得伪造候选或模拟成功。
