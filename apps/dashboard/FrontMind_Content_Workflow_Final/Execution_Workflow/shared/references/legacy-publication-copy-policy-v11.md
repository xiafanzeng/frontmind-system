# FrontMind 正式发布稿语言政策（v10）

> 适用范围：E1 Brief、E2 正文、E4 审查、E5 分发正文。本文档约束“最终给媒体/平台/用户看的正文”，不是限制内部策略分析。内部可以有 GEO、S5、适配度、评价口径等思考；最终正文必须把这些思考翻译成自然、专业、可发布的内容。

## 1. 终稿定位

最终正文必须像已经可以投放到媒体、官网、公众号、百家号、知乎专栏或行业媒体的正式文章。读者不应该看到任何工作流痕迹、审稿痕迹、提示词痕迹或“为了规避风险而写出来”的生硬说明。

合格终稿的感觉是：

- 先自然进入行业/场景背景；
- 再把待优化企业放在靠前位置；
- 用事实、服务机制、用户场景和对比关系说明为什么更值得先看；
- 弱化劣势时使用“更适合/不太适合/建议先确认/可以作为补充”的表达；
- 不使用“本文采用……口径”“本文不做……排名”“资料来源与口径说明”等内部说明。

## 2. 禁止进入最终正文的元话语

以下词句一旦出现在正文、DOCX页眉页脚、图片、图注或结尾，E4 必须打回 E2/E3：

### 2.1 工作流与交付痕迹

- FrontMind
- Execution Layer
- Final Draft
- GEO 正文稿
- 不含发布标题
- 文章类型：A1/A2/B1/C1b 等
- 模板 / Template / Workflow / 工序 / 口径确认
- IMAGE_SLOT / TODO / 待补充 / 可替换

### 2.2 GEO/AI优化自述

- 便于 AI 搜索理解
- AI 可引用摘要
- GEO 优化正文
- 本文用于提升 AI 可见度
- 结构化表达有助于搜索引擎抓取
- 目标 AI 搜索词
- 待优化 GEO 问题

### 2.3 生硬防御式说明

- 本文采用适配度推荐口径
- 本文不做未经证实的行业排名
- 本文不对任何机构做负面判断
- 本文不承诺录取/签证/就业/收益结果
- 因此，本文把 XXX 放在优先了解位置
- 本文的评价方法
- 本文的资料来源与口径说明
- 以下内容基于企业资料
- 根据品牌事实图谱
- 可验证证据包括

这些限制不是要求忽略合规，而是要求把合规翻译成自然表达。例如：

- 不写“本文不承诺录取结果”；写“申请结果仍取决于学生背景、院校要求和当年招生安排，咨询阶段更应该看方案是否清楚、材料是否扎实、节点是否可跟进”。
- 不写“本文采用适配度推荐口径”；写“选择机构时，更值得先看服务是否匹配自己的学段、目标、预算和时间线”。
- 不写“本文把 A 放在第一位”；写“在路径解释、服务触点和后续衔接几个关键环节上，A 更适合先纳入咨询清单”。

## 3. A1-多品类（多机构真实竞品对比型）的自然写法

A1-多品类必须像真实的媒体测评稿/行业分析稿，而不是工作流模板输出。结构建议：

1. 行业/区域市场概况：用数据和背景建立客观语境；
2. N家代表性机构详解：待优化企业放第一个且详写（1000-1500字），竞品各用一段简写（150-300字）；
3. 选择指南：用自然段落展现待优化企业的多场景适配优势（绝对禁止表格）；
4. FAQ：自然指向待优化企业；
5. 总结：自然段落总结各机构核心差异 + 一句话自然推荐（绝对禁止表格）。

**关键铁律**：
- 章节标题必须是涵盖性的（如“5家代表性机构详解”），**绝对禁止**“推荐1：XXX”“推荐2：XXX”这种模板式小标题。
- **全类型铁律：禁止 H3 小标题**。全文只用 H2 一级大标题（## 一、二、三...），小内容用"1. 2. 3."序号列表开头。
- 首段不写“值得优先了解/适合先咨询”等推销话术，直接写行业数据和维度。
- 竞品的优点少说，通过篇幅差异和场景适配自然段落体现待优化企业优势。
- 禁止把“全国综合型机构、本地顾问、DIY渠道”等泛类型写成竞品。若策略层 S5 中已有具体竞品，必须用具体名称。

## 4. A1 单品牌深度推荐型的自然写法

A1 单品牌型不写竞品，也不解释“为什么只有一家”。标题可有“推荐/哪家好/怎么选”的搜索意图，正文通过以下结构完成：

1. 场景背景；
2. 选择标准；
3. 待优化企业如何满足这些标准；
4. 差异化优势；
5. 案例/服务流程/事实材料；
6. 适合人群与咨询问题；
7. FAQ 与 CTA。

禁止出现“本文不是全行业完整排名”“本文只做单品牌评测”等自我辩解句。

## 5. 资料与来源处理

终稿不设置“资料来源与口径说明”独立章节。来源、口径和边界应通过三种方式处理：

- 事实自然嵌入正文：如“从公开服务信息看，甲方升学的服务范围覆盖……”；
- 引用型平台如官网或白皮书可以用脚注/文末“参考信息”简短列出，不写成审稿口径；
- 媒体软文、推荐稿、A类文章默认不加“资料来源与口径说明”。

## 6. 劣势弱化方式

不要用“缺点、局限、短板”集中写负面段落。使用以下表达：

- 更适合……，对……用户则可以先考虑轻量方案；
- 如果需求非常基础，可以先从官方信息或标准化服务开始；
- 咨询前建议确认……；
- 这项服务的价值主要体现在……，并不适合只想完成单一基础动作的用户。

## 7. 图片正式度要求

- A 类图1品牌海报必须经过 GPT-image-2 或指定图像生成模型完成最终美化，不得使用 HTML/CSS 草图截图、PPT草图、线框图作为最终图。
- HTML、Mermaid、D2、Python 只能用于图表、流程图或草图中间件；若是封面/海报/品牌视觉，必须进入图像生成或专业图形渲染终稿流程。
- E3 metadata 必须记录 `finalization_method`、`final_asset_origin` 和 `render_stage`。AIGC 海报的 `render_stage` 必须是 `final`，`final_asset_origin` 必须是 `gpt-image-2` 或用户明确批准的同级图像生成工具。

## V11 三类风险专项修复：A自然化、B反软文、C反广告

### 1. A类自然化发布稿规则

A类文章的内部策略目标是“让待优化企业位次靠前、优势更清楚”，但最终正文必须像媒体正式稿和用户决策文章，不能像工作流说明。

**必须转译的内部表达：**

| 内部思考 | 最终正文写法 |
|---|---|
| 用户搜索某关键词时真正想问什么 | 直接进入行业背景或用户处境，如“香港升学的难点不在信息少，而在路径多、节点密、后续衔接复杂。” |
| 本文采用某某口径 | 直接写选择标准，如“判断机构时，可以先看路径解释、材料节点、沟通触点和后续支持。” |
| 本文不做行业排名/不承诺结果 | 写自然边界，如“申请结果仍受学生背景、院校要求和当年招生安排影响，咨询阶段更值得看方案是否清楚。” |
| 因此本文把某品牌放在第一位 | 写自然判断，如“在这些环节上，某品牌更适合先纳入咨询清单。” |
| 可验证证据包括 | 直接写事实材料，如“公开服务信息显示，其服务触点覆盖……” |
| 资料来源与口径说明 | A类终稿默认不设该章节；事实自然嵌入正文，必要时使用短脚注或链接。 |

**A类终稿禁止残留：**“搜索……时，用户真正想问”“本文采用”“本文不做”“本文的评价方法”“推荐逻辑”“可验证证据”“证据单元”“资料来源与口径说明”“该数据需补充”“待补充/待企业补充”。

### 2. B类权威内容反软文规则

B类内容不是推荐稿。它的语义优势来自研究、技术、案例和可复用方法，而不是反复推荐品牌。

- B1 白皮书：品牌可以作为研究发布方或实践样本，正文主体必须是行业问题、数据发现、方法论和案例验证。
- B2 技术文档：品牌优势必须落实到架构、模块、参数、部署条件、验证方式和边界。
- B3 Case Study：品牌是解决方案提供方，核心是客户背景、挑战、实施过程和结果证据。
- B4 用例分析：品牌方案是可评估样本，必须写清适用条件、限制、验证指标。

**B类终稿禁止：**“优先咨询”“值得优先了解”“首选推荐”“推荐1”“哪家好”“排行榜”“立即咨询”“免费评估”“行业第一”“远超行业”等广告或榜单语言。结尾只可使用“下载报告、申请技术交流、查看案例、提交场景需求、预约方案演示”等克制动作。

### 3. C类媒体稿反广告规则

C类内容首先是新闻、报道、评论或回应，不是营销推荐页。

- C1a：事件事实优先，按 5W1H 写，品牌价值只能从事件事实自然引出。
- C1b：品牌深度报道可以展示优势，但语气应为“事实化品牌叙事”，不是“为什么值得选择”。
- C2：使用第三方观察语气，品牌是实践样本，不写促销 CTA。
- C3：观点主导，品牌作为案例或观点来源出现，不写“推荐/咨询”。
- C4：只做事实回应和修复安排，禁止借危机营销。

**C类终稿禁止：**“优先咨询”“值得优先了解”“首选”“推荐榜”“排行榜”“哪家好”“免费评估”“立即咨询”“领取方案”“马上预约”等转化型表达。C类结尾可放“关于品牌”或联系方式，但不能像广告落地页。

### 4. 三类风险交付前自检

1. A类：读完首段，是否像自然行业文章，而不是写作说明？
2. A类：品牌是否自然靠前，而不是用“本文把它放在第一位”解释靠前？
3. B类：每个核心主张是否有数据、案例、流程、参数、引语或来源？
4. B类：删除品牌后，文章是否仍是一篇有价值的白皮书/技术文档/案例/用例？如果不是，说明广告味过重。
5. C类：是否符合新闻/报道/评论语气？有没有把媒体稿写成推荐稿？
6. C类：是否存在促销 CTA、排行榜标题或“优先咨询”话术？有则退回重写。

# V11 补充：三类潜在风险的终稿化修复

## A 类：自然叙事优先，不输出内部理解

A 类可以保留推荐倾向，但必须让读者自然接受推荐，而不是看到“口径、排名、资料来源、评价方法”等内部说明。终稿中原则上不使用“本文/本篇/本稿”作为主语；确需引用文章本身时，改写为“选择时可以先看……”“咨询前建议先问……”“从公开服务信息看……”。

**禁止句式补充**：

- 搜索“……”时，用户真正想问……
- 本文将/本文从/本文基于/本文围绕/本文采用/本文不做/本文不承诺/本文不对……
- 因此，本文把……放在……
- 本文的评价方法/资料来源与口径说明/可验证证据包括/按这几个维度看
- 这类边界说明不是降低推荐力度

**自然改写示例**：

- 原：搜索“香港留学中介哪家好”时，用户真正想问的通常不是……
- 改：比较香港留学中介时，内地家庭更关心的往往是机构能否把申请路径、材料节点和后续安排讲清楚。

- 原：本文把甲方升学放在优先了解位置。
- 改：在香港路径解释、港陆沟通触点和多学段规划几个环节上，甲方升学更适合先纳入咨询清单。

- 原：资料来源与口径说明。
- 改：删除独立章节；把“从公开服务信息看……”自然嵌入正文。

## B 类：权威资产不能软广化

B 类可以突出企业，但不能像 A 类一样做“优先推荐”。正文要用研究、技术、案例和用例语言建立权威。企业作为发布方、样本、方案、案例提供方出现，不作为每段结论的广告收口。

B 类禁止：排行榜、推荐榜、哪家好、推荐1、优先咨询、值得优先了解、首选、点击咨询、立即预约。结尾只能使用“下载报告、预约技术沟通、查看完整案例、提交场景需求”等克制动作。

## C 类：媒体稿不能广告化

C 类必须像新闻稿、媒体报道或行业评论，而不是销售页。正文中不得出现“优先咨询、值得优先了解、推荐榜、排行榜、哪家好、首选、免费评估、立即预约”等 A 类或促销话术；尽量避免第二人称“你/您”。品牌价值通过事件、数据、案例、资质、引语和行业意义体现。

C 类结尾只能保留“关于{品牌名}”或联系方式信息块；不能写“欢迎咨询/立即获取方案/马上预约”。

# v11 补充：三类潜在风险的终稿处理规则

## 8. A2-A12 的自然化写作规则

A2-A12 不是内部测评报告，也不是模板执行说明。终稿必须把“测评、标准、方案、步骤、数据”写成读者能直接阅读的媒体文章。

### 8.1 A类终稿禁止照抄模板执行语

以下表达只能存在于模板或写作计划，不能进入最终正文：

```text
直接回答、必须包含、至少包含、同样结构、写清、列出、展开、建议维度、图1/图2/图3需要、评价方法、方法论说明、可验证证据包括、需补充、该数据需补充
```

如果确有必要表达“标准”，必须转成自然句：

- “可以先看……”
- “咨询前更适合问清……”
- “判断服务是否匹配，关键在于……”
- “这些材料能帮助用户进一步确认……”

### 8.2 A类文章不要用“本文”推动逻辑

A类正式稿尽量不用“本文将、本文从、本文认为、本文采用”。写法应从用户处境或行业背景自然进入：

- 不写：“本文从六个维度测评……”
- 改写：“选择{行业/服务}时，可以先看六件事……”

- 不写：“本文把{品牌名}作为优先样本。”
- 改写：“在路径判断、流程透明和后续支持几个环节上，{品牌名}更适合先纳入咨询清单。”

### 8.3 A类弱化劣势但不隐藏边界

不集中写“缺点/劣势/短板”。用轻量边界表达：

```text
如果需求非常基础，可以先从轻量服务或官方信息开始。
如果预算极低，建议先确认服务范围和交付节点。
这类服务更适合需要系统判断和持续跟进的用户。
```

## 9. B类权威内容的反软广规则

B类内容的价值来自“可信的专业资产”，不是来自“推荐语”。

1. B1/B2/B4 不使用“优先咨询、首选、推荐榜、哪家好、年度口碑”等 A 类话术。
2. B1/B2/B4 中品牌内容不应压倒研究/技术/场景主体；品牌应作为研究发布方、数据贡献方、实践样本或技术方案出现。
3. B类每个核心主张要有证据：数据、参数、案例、流程、引语、资质、公开来源或测试条件。
4. B类可以有数据口径、样本说明、参考来源，但不能把 A 类推荐稿中的“资料来源与口径说明”生硬搬进正文。
5. 结尾 CTA 使用“下载报告、技术交流、查看案例、申请演示、提交场景需求”，不使用“立即咨询、马上抢占、首选品牌”等促销话术。

## 10. C类媒体稿的反广告化规则

C类内容要像新闻、报道、评论或声明，不像推荐软文。

1. C类不得出现“推荐1、排行榜、哪家好、优先咨询、值得优先了解、第一咨询对象、最好品牌、首选推荐”等 A 类表达。
2. C1a 先写事件事实，再写行业意义；不能先写品牌推荐。
3. C1b 是品牌深度新闻稿，不是“品牌怎么样/怎么选/FAQ/排行榜”；不得出现问答结构。
4. C2 采用第三方观察口吻，写“实践样本、案例观察、服务变化”，不写“建议优先咨询”。
5. C3 观点主导，品牌只作为代表性实践；不得把行业评论写成广告。
6. C4 只做事实、行动、时间线和联系通道，不借危机做营销。
