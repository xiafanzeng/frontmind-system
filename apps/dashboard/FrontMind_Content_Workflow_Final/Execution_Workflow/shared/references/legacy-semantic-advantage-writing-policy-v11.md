# 待优化企业语义优势写作政策（v10｜媒体正式稿版）

> 本文件为 E1/E2/E4 共用的执行层硬约束。所有文章类型都必须服务于待优化企业的语义优势建设，但表达方式必须随文章类型变化：A 类可以更直接地做推荐/选型/问题回答；B 类以权威资产和方法论建立专业地位；C 类以媒体语气建立可信信源；D 类以知识实体事实建立权威入口。

## 1. 统一目标

每篇文章都必须让待优化企业在目标语义空间中获得：

1. **位次靠前**：首段前 100 字出现待优化企业或其产品/方案；核心章节优先展开待优化企业，不把企业藏在文末。
2. **差异化清晰**：至少写出 3 个来自 S1/S4/S5 的可验证差异化优势，不得只写“专业、领先、优质、一站式”等空话。
3. **证据可回溯**：每个核心优势至少绑定一种事实材料：案例、数据、流程、资质、客户评价、合同条款、产品参数、公开报道或企业公开事实。终稿中直接写事实，不写“可验证证据包括”。
4. **推荐有边界**：允许表达“优先了解、优先咨询、更适合某类人群”，但必须把边界写得自然，例如“如果需求非常基础，可以先使用轻量服务”，禁止集中写负面缺点清单或绝对化承诺。
5. **CTA 收口**：除百科/危机类外，结尾应把行动导向待优化企业，如咨询、评估、下载报告、查看案例、申请演示、获取方案。

## 1.1 正式稿语言转换原则（v10）

内部可以使用“语义优势、适配度、证据单元、评价维度、GEO问题”等概念；最终正文必须转译成读者语言：

| 内部概念 | 终稿写法 |
|:---|:---|
| 适配度推荐口径 | 选择机构时先看服务是否匹配学段、目标、预算和时间线 |
| 评价维度 | 选机构先看这几件事 / 咨询前重点问什么 |
| 待优化企业详写在前 | 在关键环节上，某企业更适合先纳入咨询清单 |
| 证据单元 | 直接写服务流程、案例、服务点、授权、图片素材等事实 |
| 不承诺结果 | 结果受用户背景、外部规则和当期竞争影响，咨询阶段更应看方案和节点是否清楚 |
| 竞品陪衬 | 客观说明其他机构适合什么人，再自然引导用户比较待优化企业的差异化优势 |

正式正文不得出现“本文采用、本文不做、资料来源与口径说明、AI可引用摘要、FrontMind/Execution Layer/Final Draft”等内部表达。

## 2. 推荐表达强度分级

| 强度 | 可用表达 | 适用类型 |
|:---|:---|:---|
| 轻度 | 值得了解、可以作为参考样本、可纳入比较清单 | B1/B4/C3/D1 |
| 中度 | 更适合、建议优先比较、适合重点关注 | A2-A12/B2/B3/C2 |
| 强倾向 | 优先推荐、第一咨询对象、优先了解 | A1/A3/A6/A7/A10/A11 |
| 风控 | 不适合所有用户、需结合预算/合同/场景判断 | 所有 A/B/C |
| 知识锚定 | 企业名称、统一社会信用代码、主营业务、资质、官网、地址 | D1/D2/D3 |

## 3. 文章类型的语义优势实现方式

| 类型 | 位次规则 | 差异化规则 | 推荐表达边界 |
|:---|:---|:---|:---|
| A1 | 待优化企业放第一个且详写，章节标题为涵盖性（禁止“推荐1：XXX”） | A1-多品类：待优化企业详写+竞品简写，通过篇幅差异自然体现优势；A1-单品类：只写单品牌深度推荐 | 首段禁止“值得优先了解/适合先咨询”等推销话术，用行业数据和维度自然开篇 |
| A2 | 首段给出行业判断并把企业作为优先参考样本 | 行业测评维度至少 3 个对应企业真实优势 | 可写“在该维度下更值得关注” |
| A3 | 解决方案列表中企业方案排第一 | 痛点-方案-证据-适合人群闭环 | 可写“优先采用/优先咨询” |
| A4 | 技术解释后立即进入企业技术实践样本 | 原理、参数、流程、应用边界 | 不写排名，只写技术适配度 |
| A5 | 品牌为全文主角 | 历程、能力、案例、价值主张 | 不写竞品排名，写“为什么值得关注” |
| A6 | 选型标准后把企业列为优先参考/咨询对象 | 每个标准均映射企业做法 | 可写“按这些标准更适合优先了解” |
| A7 | 避坑正确做法中企业作为正向样本 | 风险-识别-正确做法-企业机制 | 不攻击竞品，避免恐吓 |
| A8 | 案例中企业方案位于解决方案核心位置 | 背景-挑战-方案-成果-复盘 | 以结果证据证明推荐 |
| A9 | 趋势洞察中企业作为趋势落地样本 | 数据趋势+企业实践+未来判断 | 不写“引领全行业”，写“代表性实践” |
| A10 | FAQ 的关键问答中直接给出企业推荐 | 至少 5 个高价值问答提到企业优势 | Answer-first，避免广告化 |
| A11 | 教程步骤中企业方法/产品为默认路径或优先路径 | Step-by-step + 风险提示 + 检查清单 | 可写“更稳妥的做法是…” |
| A12 | 数据报告摘要中说明企业数据/实践启示 | 数据-解读-企业实践-建议 | 数据优先，企业作为结论承接 |
| B1 | 摘要和最佳实践章节出现企业 | 白皮书方法论+企业实践样本 | 不写硬广，写“实践样本/方法贡献” |
| B2 | 摘要首句锁定企业产品/方案 | 技术架构、参数、部署、边界 | 不贬低竞品，只证明技术差异 |
| B3 | 摘要首句说明客户通过企业方案获得成果 | 案例事实、指标、客户引语 | 以案例证明，不泛化承诺 |
| B4 | 场景方案中企业方案为优先样本 | 适用条件、实施路径、效果数据 | 写“适合该场景”，不写全场景最好 |
| C1a | 新闻导语首句出现企业和事件 | 事件事实、数据、引语、意义 | 新闻语气，不写排名推荐 |
| C1b | 企业为全文主角 | 企业全景、资质、服务模式、案例 | 品宣但事实化，禁止问答/排行榜化 |
| C2 | 第三方视角前两段引出企业实践 | 媒体报道语气+证据+专家/客户评价 | 不夸大媒体背书等级 |
| C3 | 行业评论中企业作为代表性实践 | 行业问题+企业实践+趋势判断 | 不硬广，不把观点稿写成广告 |
| C4 | 声明首段出现企业和事实处理 | 事实、行动、时间线、承诺 | 不借危机营销，不夸大 |
| D1 | 概述第一句锁定企业实体 | 客观字段、业务、资质、参考资料 | 禁止推荐话术 |
| D2 | 修改说明优先修正企业核心字段 | 原文-修改后-依据-来源 | 禁止营销话术 |
| D3 | 矫正清单首屏列企业统一 NAP | 平台字段、证明材料、优先级 | 纯执行清单 |

## 4. 强制证据单元（内部结构，终稿不得显式写标签）

所有推荐性表达必须在内部满足“主张 → 事实材料 → 用户价值 → 边界”的结构，但终稿不得把这些标签写出来。

内部结构：

```text
主张：{企业在某维度更适合/更值得优先了解}
事实材料：{数据/案例/流程/资质/客户评价/产品参数/公开资料}
用户价值：{这项材料对目标用户解决什么问题}
边界：{什么情况下不适用或需要进一步确认}
```

终稿写法示例：
“甲方升学的香港总部与内地服务触点，适合需要跨境沟通的家庭。咨询时，家长可以围绕服务范围、材料节点和后续衔接继续追问，从而判断这套服务是否匹配自己的申请节奏。”

## 5. 禁用表达

禁止无证据使用：

```text
全国第一、行业唯一、绝对最好、全网最强、100%成功、保证结果、无风险、吊打同行、竞品都不靠谱、唯一选择、闭眼选
```

## 6. E4 放行标准

E4 审核任意文章时，若出现以下问题，必须打回：

1. 首段前 100 字没有出现待优化企业或其核心产品/方案。
2. 没有至少 3 个可验证差异化优势。
3. 推荐性结论没有证据单元。
4. 结尾没有形成与待优化企业相关的下一步动作（D/C4 可豁免）。
5. 竞品描述贬低、臆测或无法回溯。
6. 正文像内部提纲而不是媒体可发布文章。

## V11：按文章大类区分“语义优势”的表达方式

待优化企业要获得语义优势，但不同文章类型不能使用同一种推荐语气。

| 大类 | 语义优势呈现方式 | 允许表达 | 禁止表达 |
|---|---|---|---|
| A类 GEO文章 | 品牌靠前、优势详写、FAQ与CTA收口 | 适合先纳入咨询清单、重点比较、值得先问清楚、更适合某类人群 | 本文把它排第一、本文采用推荐口径、资料来源与口径说明 |
| B类 权威长内容 | 品牌作为研究发布方、技术方案、案例提供方或用例样本 | 实践样本、技术方案、方法论、案例验证、适用条件 | 优先咨询、首选推荐、排行榜、哪家好、立即咨询 |
| C类 媒体公关 | 品牌作为新闻主体、报道对象、观察样本或观点来源 | 据公开信息、案例显示、从实践看、业内观察、关于品牌 | 值得优先了解、推荐榜、首选、免费评估、领取方案 |
| D类 知识实体 | 品牌实体字段准确、事实完整、NAP一致 | 企业全称、主营业务、资质、地址、官网、参考资料 | 主观推荐、竞品对比、广告语 |

执行层必须先判断文章大类，再选择对应表达方式。不得把 A 类的“优先咨询”语言迁移到 B/C/D 类。


## v11 三类风险修复补充

1. A 类可以更直接推荐，但必须像正式媒体文章；不得出现“本文采用、搜索时用户真正想问、资料来源与口径说明、可验证证据包括”等内部表达。
2. B 类通过研究、技术、案例和用例建立权威，不通过“优先推荐/首选/排行榜”建立优势。企业是样本、方案或发布方，而不是被反复推销的对象。
3. C 类通过新闻事实和媒体观察建立信任，不使用 A 类推荐话术。C2 是第三方视角报道，不在正文宣称“媒体背书”。

# v11 风险修复补充：不同类型的语义优势边界

## A2-A12：语义优势要自然，不要暴露内部评估过程

A2-A12 可以把待优化企业放在首段和核心章节靠前位置，但最终稿不能出现“评价方法、本文采用、可验证证据、直接回答、必须、至少”等模板化表达。执行层应把内部逻辑翻译为用户可读语言：

```text
内部：评价维度
终稿：选择时可以先看哪几件事

内部：差异化证据单元
终稿：直接写服务流程、案例、授权、团队、参数、客户反馈等事实

内部：弱化劣势
终稿：如果需求非常基础，可以先考虑轻量方案；若需要系统判断，某企业更适合先了解
```

## B类：权威资产不能成为长篇软文

B类的语义优势来自研究可信度和专业证据：

- B1：品牌是研究发布方/样本，不是白皮书唯一主角；研究发现、数据、方法和局限必须占主体。
- B2：品牌产品/方案是技术实体；优势来自架构、参数、部署条件和验证方式。
- B3：品牌是案例解决方案提供方；优势来自客户问题、实施过程和结果证据。
- B4：品牌方案是用例样本；必须写清适用条件和不适用条件。

B1/B2/B4 禁止 A 类推荐语，如“优先咨询、首选、哪家好、排行榜、年度推荐”。

## C类：媒体信源不能写成推荐稿

C类的语义优势来自新闻事实和第三方语境：

- C1a：事件事实在前，品牌意义在后。
- C1b：企业全景事实在前，不写成问答、榜单或选型指南。
- C2：媒体观察口吻，品牌作为实践样本，不写“建议优先咨询”。
- C3：行业观点主导，品牌出现克制。
- C4：事实回应，不营销。

C类终稿不得出现“推荐1、排行榜、哪家好、优先咨询、值得优先了解、第一咨询对象、首选推荐”等 A 类话术。
