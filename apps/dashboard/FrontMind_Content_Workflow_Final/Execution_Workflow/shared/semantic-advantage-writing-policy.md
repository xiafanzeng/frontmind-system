# 企业语义优势写作政策

企业优势来自“主张 -> 可核验事实 -> 用户价值 -> 适用条件”，不能来自付费关系、人工排序、竞品贬低或形容词堆叠。

## 强度

- 事实描述：有一个可靠来源即可，按来源限定范围。
- 条件性适配：“如果更重视 A，可优先比较 X”，需要共同评价维度和对应证据。
- 推荐/比较结论：需要 P01/P02/P03 对应的真实候选、统一维度和足以支持实际措辞强度的内容；不统一要求原创采样或第三方材料。
- 最佳、领先、第一等强结论：只有清楚范围、时间、方法和高强度证据时才可能使用；一般稿件默认禁用。

## 自然进入位置

E4 在结构化 `brand_intervention` 指定品牌出现的功能：被推荐候选、比较对象、解决方案、技术实体、案例提供方、事件主体、报道主角、观点样本或回应主体。品牌不得在所有模式都以前 100 字硬插或固定 CTA 收尾。

## 质量检查

- 最终实际写入的重要企业事实能找到支持来源，不要求所有上传资料形成完整 claim/source 图谱；
- 说明适用对象、门槛和不适用情况；
- 竞品使用相同标准；
- P10/P15 中品牌不能吞没研究或观点主体；
- P13/P16 不借事件或风险营销；
- 正文不出现“语义优势、证据单元、推荐逻辑、内部评价维度”等生产术语。
