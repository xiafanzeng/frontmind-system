# 内容趋势研究框架

框架用于提出问题和解释可靠信号，不替代来源。S3 不需要机械运行全部框架，也不输出综合趋势分数。

## 1. PEST：外部条件是否改变

- **Policy**：法规、监管、标准、公共政策；优先原始文件并记录生效范围。
- **Economic**：成本、预算、交易、供需；记录指标定义、时间和地域。
- **Social**：用户习惯、文化语言、组织行为；区分定量变化与个别现象。
- **Technology**：能力、成本曲线、接口、基础设施；区分论文/演示与可用产品。

输出的是“发生了什么变化、何时、影响谁、对内容有什么影响”，不是四象限报告。

## 2. 竞争结构：选择标准是否改变

借用五力思路检查：新进入者、替代方案、供应侧依赖、买方议价和同类竞争是否让用户开始问新的问题或采用新的判断标准。

只有变化能连接 S4 decision context 时保留。例如“出现新替代技术”需要说明它改变哪个决策维度，而不是预测整个行业胜负。

## 3. 品类生命周期：解释需求成熟度

- 萌芽：定义、机制、风险和可信证据更重要；
- 增长：选型标准、场景适配、实施与案例更重要；
- 成熟：同口径比较、替换成本、服务边界更重要；
- 重构/衰退：迁移、替代、存量风险与新场景更重要。

生命周期判断必须有采用、供给、标准、搜索/讨论语言或交易等可观察信号。不得只凭主观印象贴阶段标签。

## 4. 弱信号与文化迁移

观察某个概念、隐喻、做法或价值判断是否从另一领域进入当前品类。记录：起源语境、迁移路径、早期使用者、语义是否改变、是否可能引发误解。

社交热度只能说明关注，不等于真实采用或商业增长。弱信号默认较低 confidence，除非出现独立、多类型验证。

## 5. 证据三角

普通趋势优先组合不同类型来源：

1. 原始/权威事实：法规、标准、论文、产品发布、公开数据；
2. 行为/市场事实：交易、采用、调查、实际使用；
3. 语言/文化事实：搜索表达、社区讨论、媒体叙事。

至少两个独立来源；单一权威原始文件可标 `primary_authoritative`。同一新闻稿的多次转载不算多源。

## 6. 内容影响门

一个趋势只有能改变至少一项才进入输出：

- 当前文章是否采用该观点以及放在哪一段；
- 标题或开篇的时效背景；
- 必须解释的新实体/机制；
- 必须更新的比较维度；
- 风险、限制或 freshness rule；
- 已知 S7 问题资产的时效补充（不生成新选题）。

不能说明内容影响的信号放研究日志，不进入 Reference Pack。时间窗由品类变化速度决定，不强制 3/6/12 月预测。
