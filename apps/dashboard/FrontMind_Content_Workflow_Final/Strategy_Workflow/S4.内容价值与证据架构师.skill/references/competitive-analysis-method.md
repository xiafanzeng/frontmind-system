# 文章比较与竞品证据方法

本方法保留原竞品研究中的识别、维度选择和矩阵思想，但只生产文章可用的比较边界，不做品牌排名或 AI 平台占位诊断。

## 1. 何时需要比较

只有当 S4 decision context 包含替换、选型、采购或方案评估，或 S7 的 `entry_category` 指向竞品比较/行业筛选时才建立比较对象。没有真实决策需求时，不为了“显得完整”列竞品。

## 2. 候选来源

- S2 已记录的直接与间接替代方案；
- 用户、销售或采购材料明确提到的候选；
- 权威品类目录、公开招标/采购标准中的同类方案；
- S3 可靠趋势中出现的新替代方案（若 S3 已运行）。

AI 自动回答、搜索摘要或无出处榜单只能产生研究线索，不能成为比较事实。

## 3. 比较维度

从读者决策标准选择维度，通常包括：

- 能力/功能及其明确边界；
- 适用场景与不适用场景；
- 价格口径、总成本与有效日期；
- 实施、迁移、兼容和维护；
- 安全、合规、资质及适用范围；
- 服务范围、交付条件和 SLA；
- 有方法说明的性能/效果数据。

“品牌影响力”“综合实力”等不可观测维度不能直接评分。维度权重只有在客户确认的决策模型或真实调研支持时才使用。

## 4. 同口径矩阵

每一个格子记录：

```text
对象 + 维度 + 观察值 + 单位/定义 + 时间点 + 地域/版本 + source_ref + evidence_precision
```

缺失写 `unknown`，不能自动补成“没有”。不同计价单位、版本、样本或时间点必须先归一或明确不可比。

## 5. 来源要求

- 品牌自身能力可用第一方资料，但必须按 claim registry 状态表达；
- 竞品能力优先使用竞品官方资料并明确“其官方资料称”；
- 胜负、效果和行业位置需要同口径的独立第三方数据；
- 用户评论只说明出现过某种体验，不代表总体；
- 所有价格、版本和政策信息必须有重查规则。

## 6. 文章允许输出

- 解释应如何选择比较维度；
- 展示有来源、同口径的事实差异；
- 指出不同条件下各自适用性；
- 明确数据缺口和不能比较的部分。

禁止：伪造总分、用第一方口号判定整体领先、用局部案例外推、将相关性写成因果、把旧时点数据写成当前状态。

## 7. Comparison Boundary 对象

S4 输出至少包含：`allowed_entities`、`allowed_dimensions`、`required_source_types`、`same_basis_rules`、`freshness_rules`、`prohibited_inferences`、`fallback_without_evidence`。S5 继承措辞，S7 用它生成 comparison/alternative/evaluation/risk 类问题。
