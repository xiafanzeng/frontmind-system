# 内容证据与语义完整性边界

本文件保留原诊断/语义审计阶段中真正服务文章生产的部分，去掉 AI 可见度、排名、引用份额和品牌评分。

## 来源能证明什么

| 来源 | 通常可以证明 | 通常不能单独证明 |
|---|---|---|
| 官方网站/客户文件 | 品牌身份、产品说明、官方主张 | 行业领先、效果优于竞品、普遍用户评价 |
| 监管/标准/论文原文 | 制度、定义、研究结果及其限定范围 | 对特定品牌的未研究结论 |
| 独立第三方测评/数据 | 其样本、时间与方法范围内的比较 | 超出样本和时点的普遍结论 |
| 客户案例 | 特定客户、特定条件下发生的结果 | 对所有客户的承诺 |
| 用户评论/社区 | 某些用户表达过的体验或疑问 | 总体满意度、客观性能 |
| AI 推断 | 形成研究假设 | 任何可发布事实 |

## 证据精度

- `exact`：直接支持已定位的精确数据或原句；
- `claim`：直接支持该声明及其限定条件；
- `branch`：只支持某个主题范围，默认归因表达；
- `document`：只能定位到整份文件；
- `source`：只能定位到来源实体，无法定位具体段落；
- `none`：无可用证据。
- `unknown`：上游没有提供可判断的精度。

身份可信与定位精度是两个维度。`verified_first_party + branch` 仍不能自动变成逐句客观事实。

## 允许表达

| allowed_usage | 写作规则 |
|---|---|
| public_fact | 保留时间、地域、对象、量级等限定条件 |
| public_with_qualification | 用“官方资料显示/品牌表示”，不得去掉归因与 caveat |
| internal_only | 只进入缺口或待核验清单 |
| do_not_use | 不进入 brief、正文、图注或 FAQ |

## 语义完整性（不打分）

高质量文章不能只重复口号。对每个主题检查是否有：

- 核心实体及其准确关系；
- 用户任务、触发情境与约束；
- 机制或工作原理；
- 能力与明确边界；
- 比较维度而非无依据胜负；
- 证据、反例、限制或不适用条件；
- 下一步决策所需信息。

这些是覆盖检查，不是 BSAS 或 AI 可见度分数。缺失项进入 S4 research gaps 或 S7 unanswered gaps，不得由模型补写。
