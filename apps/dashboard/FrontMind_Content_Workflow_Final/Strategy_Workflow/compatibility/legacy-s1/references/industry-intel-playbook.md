# 行业情报获取手册 (Industry Intelligence Playbook)

> **版本**：v1.0 | **归属**：S1 品牌资产知识库 Stage A-3  
> **设计原则**：S1 负责**采集原始信号与事实**，S3 负责**分析推导与趋势判断**。本手册确保 S1 在知识库构建阶段就完成全面的公共情报采集，使下游节点（S3/S4/S8/E1）可直接消费而无需重复搜索。

---

## 一、行业集群分类体系

基于业务特征和信息获取路径的差异，将所有行业归为 **6 大集群**：

| 集群 ID | 集群名称 | 核心特征 | 包含行业（示例） |
| :--- | :--- | :--- | :--- |
| **C1** | 本地生活服务 | 有门店、有线下体验、有第三方平台评价 | 酒店/民宿、餐饮/茶饮、教育/培训、零售/连锁、医美/健身/丽人、宠物医院、药店、口腔诊所 |
| **C2** | 消费品与零售 | 有实物商品、有电商评论、有社交种草 | 食品、酒水、服饰鞋帽箱包、数码家电、日用百货、个人护理、玩具、家装家具 |
| **C3** | B2B 与企业服务 | 决策链长、重案例与资质、重行业报告 | 制造行业、企业服务、商务服务、软件工具、通讯和IT服务、工业工程和安保 |
| **C4** | 医疗与健康 | 强监管、重资质、重口碑与信任 | 消费医疗全系列、重度医疗全系列、医疗器械、药品、保健品 |
| **C5** | 文化教育与内容 | 重内容质量、重用户口碑、重平台表现 | 教育、游戏、出版发行、数字内容创作、文化体育娱乐活动、互联网内容资讯服务 |
| **C6** | 专业服务与特殊行业 | 重资质合规、重政策敏感度、信息获取路径特殊 | 金融行业、法律行业、能源和供应、交通运输和仓储、农林牧渔和采矿、国家机构协会 |

> **★ 判定规则**：一个品牌可能同时属于多个集群（如"连锁药店"同属 C1+C4），此时取**所有匹配集群的并集**执行采集。

## 二、各集群信息获取路径详解

### C1：本地生活服务集群

**触发条件**：品牌有线下门店 / 有第三方平台可查评价 / 行业属于本地生活/旅游出行/消费医疗（区域性）

#### 必采信息矩阵

| 信息维度 | 必查平台 | 搜索策略 | 采集目标 | 输出字段 |
| :--- | :--- | :--- | :--- | :--- |
| 平台评分 | 大众点评、美团、携程（酒旅）、高德地图 | `{品牌名} + {平台名}` | 综合评分、评论数、星级分布 | `platforms_scanned[]` |
| 用户评论 | 大众点评、美团、小红书 | 进入品牌主页，按时间排序 | 最新 20 条代表性评论（好评/差评各半） | `positive_themes[]`, `negative_themes[]`, `raw_reviews[]` |
| 门店外观 | 高德地图、百度地图、大众点评 | `{品牌名} 门头` / 地图街景 | 门头照、外立面、招牌设计 | `storefront_images[]` |
| 环境照片 | 大众点评、小红书、携程 | 用户上传的环境图 | 内部环境、装修风格、空间布局 | `storefront_images[]` |
| POI 信息 | 高德地图、百度地图 | `{品牌名} + {城市}` | 地址、坐标、周边配套、交通 | `poi_info{}` |
| 价格信息 | 美团、携程、大众点评 | 品牌主页价格栏 | 客单价/房价区间、套餐价格 | `competitive_context.price_positioning` |
| 竞争环境 | 高德地图、大众点评 | 地图搜索同品类 | 周边 500m 内同类竞品、评分对比 | `competitive_context{}` |

#### 行业细分补充规则

| 细分行业 | 额外必查 | 额外采集目标 |
| :--- | :--- | :--- |
| 酒店/民宿 | 携程、飞猪、去哪儿 | 房型结构、设施清单、早餐评价、隔音评价 |
| 餐饮/茶饮 | 饿了么、抖音团购 | 招牌菜/爆款产品、出餐速度、外卖评分 |
| 教育/培训 | 知乎、天眼查 | 师资背景、课程体系、退费投诉、办学资质 |
| 医美/口腔/植发 | 新氧、更美、小红书 | 医师资质、术后效果评价、价格透明度 |
| 健身/瑜伽 | 大众点评、小红书 | 教练评价、器械环境、私教价格、退卡政策 |
| 宠物医院 | 大众点评、小红书 | 医师专业度、收费透明度、急诊能力 |

| 方法论 | 按平台矩阵逐一搜索采集 | PEST 分析、波特五力、生命周期定位、文化弱信号识别 |

| 质量标准 | 每条信号有来源 URL + 采集时间 | 每个趋势至少 2 条信号交叉验证 |
| 时效要求 | 优先采集最近 6 个月数据 | 基于 S1 数据进行 3/6/12 月窗口预判 |

## 四、PEST 预扫描框架（S1 降维版）

> S3 使用完整 PEST 框架进行深度分析。S1 在此阶段仅执行**PEST 预扫描**——即按四维度采集原始政策/经济/社会/技术信号，不做深度推导。

### 4.1 S1 PEST 预扫描操作指引

| PEST 维度 | S1 搜索策略 | 采集目标 | 存储位置 |
| :--- | :--- | :--- | :--- |
| **P（政策）** | `{行业} 政策 2025 2026` / `{行业} 监管 新规` | 最新 3 条相关政策标题+核心条款摘要 | `signal_snapshot.pest_signals.political[]` |
| **E（经济）** | `{行业} 市场规模` / `{品类} 增速` | 市场规模数据、增速数据（附来源） | `signal_snapshot.pest_signals.economic[]` |
| **S（社会）** | `{品类} 消费趋势` / `{品类} 年轻人` | 消费习惯变化信号、人群偏好变化 | `signal_snapshot.pest_signals.social[]` |
| **T（技术）** | `{行业} 技术突破` / `{品类} AI 数字化` | 技术变革信号、数字化趋势 | `signal_snapshot.pest_signals.technological[]` |

### 4.2 波特五力预扫描（S1 降维版）

| 五力维度 | S1 搜索策略 | 采集目标 |
| :--- | :--- | :--- |
| 现有竞争者 | `{品类} 品牌排名` / `{品类} 市场份额` | 头部品牌列表、CR5 数据 |
| 新进入者 | `{品类} 新品牌` / IT桔子融资 | 近 12 月新进入者列表 |
| 替代品 | `{品类} 替代` / `{需求} 解决方案` | 替代方案列表 |
| 买方议价力 | 电商评论中的价格敏感度 | 用户对价格的态度 |
| 供方议价力 | `{品类} 原材料 涨价` | 供应链变化信号 |

> **★ 关键约束**：S1 的 PEST/五力预扫描**只采集原始信号**（标题+摘要+URL+时间），**不做评分和趋势判断**。评分和推导是 S3 的专属职责。

## 五、采集执行优先级与时间预算

### 5.1 按集群的采集深度分级

| C4 医疗 | **深度采集**（合规优先） | 重点投入 | 资质验证 + 患者评价 + 监管记录 |
| C5 文化教育 | **中度采集** | 适度投入 | 平台表现数据 + 用户口碑 + 行业排名 |
| C6 专业服务 | **基础采集** | 基本投入 | 监管资质 + 政策环境 + 风险排查 |

### 5.2 全网信号源采集优先级

| 优先级 | 信号源类型 | 执行条件 |
| :--- | :--- | :--- |

### 6.2 S3 消费方式

### 7.1 Stage A-3 完成度评分标准

| 评分项 | 满分 | 评分规则 |
