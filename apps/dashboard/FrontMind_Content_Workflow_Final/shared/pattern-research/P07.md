# P07｜选型与价格指南

- 模板版本：`2.3.0`
- 核心问题：在具体需求和预算下，价格由什么构成，采购前该比较和核对什么？
- 研究用途：结构、子问题、证据位置、视觉论证、FAQ、优缺点与不可借鉴元素
- 运行边界：本档案只向 E4 提供结构动作；链接不能证明客户、竞品或公共事实。

## 触发条件

- 问题询问价格、费用、预算、怎么买或如何选型
- 时间、版本或使用规模会显著影响答案

## 固定专业骨架

| 组件 | 编辑任务 | 读者收获 |
|---|---|---|
| `P07_component_direct_answer` | 先回答可公开价格区间或最重要的选型判断 | 读者先获得预算与选择锚点 |
| `P07_component_budget_context` | 锁定需求、数量、币种、地区、版本、日期和预算前提 | 读者知道价格适用于哪种购买情境 |
| `P07_component_price_structure` | 拆分一次性费用、持续费用、变量和总成本 | 读者避免只比较表面报价 |
| `P07_component_selection_dimensions` | 用需求相关维度平行说明方案，不为凑表格制造空项 | 读者能把规格转成选择结果 |
| `P07_component_purchase_check` | 提供询价、验真、合同、交付和退出检查动作 | 读者知道采购前该问什么 |
| `P07_component_faq` | 回答优惠条件、增项、退款、续费和价格变动 | 读者减少后续费用意外 |
| `P07_component_conclusion` | 把建议绑定预算与使用条件，不输出脱离口径的最低价 | 读者可形成自己的采购短名单 |

## 可选模块与证据降级

- `P07_optional_total_cost`：持续使用成本重要；估算总拥有成本构成。证据：周期、用量、增项和退出费用。
- `P07_optional_quote_checklist`：需要线下询价；给统一询价问题清单。证据：同口径报价项目。
- 降级｜没有公开价格：解释价格变量并给询价动作，不编造区间。
- 降级｜候选报价口径不同：取消横向数字比较，改为成本构成核对。

## 读者问题、反对意见与品牌介入

- 子问题：价格对应什么版本和服务范围？
- 子问题：一次性与持续费用分别有哪些？
- 子问题：哪些需求变量会改变报价？
- 子问题：候选应按什么同口径维度比较？
- 子问题：合同和退出条款要检查什么？
- 反对意见：低价是否遗漏必要服务？
- 反对意见：公开价格是否已经过期？
- 反对意见：比较是否混用了月费、年费或项目费？
- 品牌自然介入：在预算前提与价格构成之后呈现品牌方案，让价格与交付内容、适用规模和限制同时出现。

## 标题与视觉

- 标题公式：{产品}多少钱？价格构成与选型重点
- 标题公式：{预算}内怎么选{品类}：费用、能力和合同检查
- 标题公式：购买{产品}前要算清的{数字}项成本
- 标题公式：{地区}{服务}价格怎么看：先统一这些口径
- 视觉 `navigate`：成本变量多；价格构成图。
- 视觉 `explain`：采购流程复杂；询价—验真—合同—交付流程图。
- 视觉 `prove`：使用具体报价；带日期、币种和条件的价格卡。

## 失败样例与禁止行为

- 失败样例：只列一个吸引人的起步价，不交代版本、用量、增项、持续费用和时间口径。
- 禁止：编造价格区间或优惠
- 禁止：混用不同币种、周期和版本
- 禁止：把最低价直接等同最高性价比
