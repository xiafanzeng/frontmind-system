# FrontMind 品牌全域词库适配器

本任务只使用随任务附加的、由 FrontMind 生成的安全知识快照 ZIP。不要请求或读取客户原始知识库 ZIP，也不要使用证件、授权材料、证据附件或隐藏文档。

完整执行上游 `generate-brand-question-universe-final-v2-20260819.zip` 中的规则。先做当前公开网络研究，再生成恰好 160 行。最终只通过 structured output 的 `payload` 字符串返回 JSON；不要返回 XLSX、Markdown、代码围栏、运行日志或内部思考。FrontMind 会严格校验 JSON，并在本地可信地生成和回读 XLSX。

`payload` 必须是 JSON 字符串，内容为：

```json
{
  "schemaVersion": 1,
  "operationToken": "与任务指令完全一致",
  "research": {
    "competitors": [{ "name": "可比品牌", "url": "https://公开来源" }]
  },
  "rows": [
    {
      "序号": 1,
      "问题": "……",
      "核心词": "……",
      "核心词分类": "行业排名词",
      "问题细分": "品类发现"
    }
  ]
}
```

要求：

- `competitors` 至少两个不同的可比品牌，每项必须有公开 HTTPS 来源。
- 五列必须完整，序号连续 1–160。
- 主分类严格为行业排名词 20、竞品对比词 20、美誉舆情词 20、产品场景词 100，并按此顺序输出。
- 行业排名词中推荐类 12、选购类 4、事实清单类 4；第一行必须含“推荐”且不得含“有哪些”。
- 八个问题细分必须全部出现：品牌认知、品类发现、产品能力、竞品对比、场景方案、采购决策、信任验证、售后合作。
- 问题 8–32 个可见字符；核心词 2–24 个可见字符。
- 不得有公式、重复问题、仅标点/空白不同的重复问题或答案对象相同的重复问题。
- 不得输出热度、日期、来源列、隐藏表、公式或批注。

收到修复消息时继续使用同一个任务和原附件，只修复列出的稳定错误码并重新返回完整 160 行。
