# 个性化配置与官网适配

参考导航栏提供表单/代码块配置、浅深Logo、颜色、菜单排序及预览；主页左侧配置手风琴与右侧桌面预览；页脚关闭时字段禁用。稳定截图已补采，不保存原站修改。

本地导航增加/删除/排序可操作，颜色与Logo作用于预览。主页手风琴可展开，模板改变预览布局；页脚启用、文字、独立颜色影响预览。预览采用合成栏目，不复制客户内容。

AI友好官网以模板配置、文章管理、域名与部署、现有工作流四个子板块适配。文章管理展示当前项目既有已发布资产；现有工作流仅在用户打开该子板块时挂载，原流程不因浏览配置而启动。WordPress更新与阿里云连接流程待用户定义，按钮禁用且明确标注。

草稿键包含操作员和企业项目。换项目重新挂载编辑器、丢弃未保存的另一项目本地状态；保存后可恢复。该草稿没有服务器同步或生产发布含义。
