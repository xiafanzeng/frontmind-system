# 站点设置表单

原站结构：顶部九个Tab、白色面板、纵向字段、蓝色选中态、固定保存栏。图标建议100×100、Logo建议8:3；模板四列。已观察文章/栏目页无保存按钮，避免在原站操作可能自动保存的开关。

适配：所有设置统一本地草稿保存。语言原生select、主题/编辑器radio、文章/搜索switch；固定底栏与正文独立滚动。九个Tab支持点击和左右/Home/End键。名称、标题、邮箱、域名及导航链接验证；错误不覆盖已保存版本。

图片仅PNG/JPEG/WebP≤1MB，本地data URL；重读草稿拒绝外部图片地址和SVG。嵌入代码只保存为字符串，不插入DOM，不执行。未知发布能力显示待接入并禁用执行按钮。
